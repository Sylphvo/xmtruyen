4. Text-to-Speech Engine (AI Voice, Đa Ngôn Ngữ)

4.1 Nguồn text cho TTS

Vấn đề: Truyện tranh chỉ có ảnh, không có text sẵn. Cần nguồn narration để AI đọc.

Giải pháp — 3 nguồn text:

  1. Từ truyện chữ (nếu có): Nếu cùng bộ truyện có phiên bản text (formatType=1) → dùng content text làm narration
  2. Admin nhập thủ công: Admin soạn script narration cho mỗi ảnh (field "narration" trong form)
  3. AI OCR + Translate: Dùng OCR đọc text trong ảnh truyện (speech bubbles) → dịch sang ngôn ngữ target → TTS

4.4 Code TTS Service

📁 xomtruyen.API/Services/TtsService.cs
using System.Diagnostics;

/// <summary>
/// Gọi edge-tts (Python CLI) để tạo audio từ text.
/// Edge TTS miễn phí, chất lượng Neural, hỗ trợ Tiếng Việt.
/// </summary>
public class TtsService : ITtsService
{
    /// <summary>
    /// Tạo file audio từ text
    /// </summary>
    /// <param name="text">Nội dung cần đọc</param>
    /// <param name="voice">Voice ID (vd: vi-VN-HoaiMyNeural)</param>
    /// <param name="outputPath">Đường dẫn file output .mp3</param>
    /// <param name="rate">Tốc độ: "+0%" (bình thường), "-20%" (chậm), "+20%" (nhanh)</param>
    public async Task<TtsResult> GenerateAudioAsync(string text, string voice, string outputPath, string rate = "+0%")
    {
        // Lưu text vào file tạm (tránh lỗi escape ký tự)
        var textFile = Path.GetTempFileName();
        await File.WriteAllTextAsync(textFile, text);

        // Gọi edge-tts CLI
        var args = $"--voice \"{voice}\" --rate=\"{rate}\" --file \"{textFile}\" --write-media \"{outputPath}\"";
        
        var process = new Process
        {
            StartInfo = new ProcessStartInfo
            {
                FileName = "edge-tts",  // Cài: pip install edge-tts
                Arguments = args,
                RedirectStandardOutput = true,
                RedirectStandardError = true,
                UseShellExecute = false,
                CreateNoWindow = true
            }
        };

        process.Start();
        await process.WaitForExitAsync();
        File.Delete(textFile);

        if (process.ExitCode != 0)
        {
            var error = await process.StandardError.ReadToEndAsync();
            throw new Exception($"TTS failed: {error}");
        }

        // Lấy duration của audio file
        var duration = await GetAudioDurationAsync(outputPath);

        return new TtsResult
        {
            AudioPath = outputPath,
            DurationSeconds = duration,
            Voice = voice,
            CharacterCount = text.Length
        };
    }

    /// <summary>
    /// Tạo audio cho nhiều đoạn (1 đoạn = 1 ảnh comic page)
    /// </summary>
    public async Task<List<TtsResult>> GenerateBatchAsync(
        List<string> textSegments, string voice, string outputDir, string rate = "+0%")
    {
        var results = new List<TtsResult>();
        
        for (int i = 0; i < textSegments.Count; i++)
        {
            var outputPath = Path.Combine(outputDir, $"audio_{i:D3}.mp3");
            var result = await GenerateAudioAsync(textSegments[i], voice, outputPath, rate);
            results.Add(result);
        }

        return results;
    }

    private async Task<double> GetAudioDurationAsync(string filePath)
    {
        var args = $"-i \"{filePath}\" -show_entries format=duration -v quiet -of csv=\"p=0\"";
        var process = Process.Start(new ProcessStartInfo("ffprobe", args)
        {
            RedirectStandardOutput = true, UseShellExecute = false, CreateNoWindow = true
        })!;
        var output = await process.StandardOutput.ReadToEndAsync();
        await process.WaitForExitAsync();
        return double.TryParse(output.Trim(), out var d) ? d : 0;
    }
}

5.2 FFmpeg Command Generation

📁 xomtruyen.API/Services/VideoGenerationService.cs
public class VideoGenerationService : IVideoGenerationService
{
    /// <summary>
    /// Ghép ảnh + audio thành video MP4 bằng FFmpeg.
    /// Mỗi ảnh hiển thị đúng thời lượng audio tương ứng.
    /// </summary>
    public async Task<string> GenerateVideoAsync(VideoGenerationRequest request)
    {
        var outputPath = Path.Combine(request.OutputDir, "output_final.mp4");
        
        // 1. Tạo file input list cho FFmpeg (concat demuxer)
        var concatFile = Path.Combine(request.OutputDir, "input.txt");
        var lines = new List<string>();
        
        for (int i = 0; i < request.Pages.Count; i++)
        {
            var page = request.Pages[i];
            var duration = page.AudioDuration > 0 ? page.AudioDuration : request.DefaultDurationPerImage;
            
            // Tạo video segment cho mỗi ảnh (ảnh + duration)
            var segmentPath = Path.Combine(request.OutputDir, $"segment_{i:D3}.mp4");
            
            // FFmpeg: ảnh → video segment với duration cụ thể + hiệu ứng
            var segmentArgs = request.Transition switch
            {
                "kenburns" => $"-loop 1 -i \"{page.ImagePath}\" -i \"{page.AudioPath}\" " +
                              $"-filter_complex \"[0:v]scale=1920:1080:force_original_aspect_ratio=decrease," +
                              $"pad=1920:1080:(ow-iw)/2:(oh-ih)/2,zoompan=z='min(zoom+0.0015,1.1)':" +
                              $"d={Math.Ceiling(duration * 25)}:x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':" +
                              $"s=1920x1080,format=yuv420p[v]\" " +
                              $"-map \"[v]\" -map 1:a -c:v libx264 -preset fast -c:a aac " +
                              $"-t {duration:F2} -shortest \"{segmentPath}\"",
                              
                "crossfade" => $"-loop 1 -i \"{page.ImagePath}\" -i \"{page.AudioPath}\" " +
                               $"-filter_complex \"[0:v]scale=1920:1080:force_original_aspect_ratio=decrease," +
                               $"pad=1920:1080:(ow-iw)/2:(oh-ih)/2,format=yuv420p[v]\" " +
                               $"-map \"[v]\" -map 1:a -c:v libx264 -preset fast -c:a aac " +
                               $"-t {duration:F2} -shortest \"{segmentPath}\"",
                               
                _ => $"-loop 1 -i \"{page.ImagePath}\" -i \"{page.AudioPath}\" " +
                     $"-vf \"scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:(ow-iw)/2:(oh-ih)/2,format=yuv420p\" " +
                     $"-c:v libx264 -preset fast -c:a aac -t {duration:F2} -shortest \"{segmentPath}\""
            };

            await RunFFmpegAsync(segmentArgs);
            lines.Add($"file '{segmentPath}'");
        }

        // 2. Concat tất cả segments thành 1 video
        await File.WriteAllLinesAsync(concatFile, lines);
        
        var concatArgs = $"-f concat -safe 0 -i \"{concatFile}\" -c copy \"{outputPath}\"";
        await RunFFmpegAsync(concatArgs);

        // 3. Thêm subtitle nếu được yêu cầu
        if (request.AddSubtitles && !string.IsNullOrEmpty(request.SubtitlePath))
        {
            var subtitledOutput = outputPath.Replace(".mp4", "_sub.mp4");
            var subArgs = $"-i \"{outputPath}\" -vf \"subtitles='{request.SubtitlePath}'\" " +
                         $"-c:a copy \"{subtitledOutput}\"";
            await RunFFmpegAsync(subArgs);
            File.Delete(outputPath);
            File.Move(subtitledOutput, outputPath);
        }

        return outputPath;
    }

    private async Task RunFFmpegAsync(string arguments)
    {
        var process = new Process
        {
            StartInfo = new ProcessStartInfo("ffmpeg", arguments)
            {
                RedirectStandardError = true,
                UseShellExecute = false,
                CreateNoWindow = true
            }
        };
        process.Start();
        await process.WaitForExitAsync();
        
        if (process.ExitCode != 0)
        {
            var error = await process.StandardError.ReadToEndAsync();
            throw new Exception($"FFmpeg error: {error}");
        }
    }
}

7. Background Worker Pipeline

📁 xomtruyen.API/Services/Workers/VideoConvertWorker.cs
public class VideoConvertWorker : BackgroundService
{
    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        while (!stoppingToken.IsCancellationRequested)
        {
            var task = await _taskQueue.DequeueAsync(stoppingToken);
            if (task is VideoConvertTask videoTask)
            {
                await ProcessVideoConvertAsync(videoTask);
            }
        }
    }

    private async Task ProcessVideoConvertAsync(VideoConvertTask task)
    {
        try
        {
            await UpdateStatus(task.Id, "Processing", 0, "Bắt đầu xử lý...");

            // Step 1: Fetch ảnh comic pages
            await UpdateStatus(task.Id, "Processing", 10, "Đang tải ảnh truyện...");
            var pages = await FetchComicPages(task.ChapterIds);

            // Step 2: Fetch text narration
            await UpdateStatus(task.Id, "Processing", 20, "Đang lấy nội dung narration...");
            var textSegments = await GetNarrationText(task);

            // Step 3: Generate TTS audio cho từng segment
            await UpdateStatus(task.Id, "Processing", 30, "Đang tạo audio TTS...");
            var audioResults = await _ttsService.GenerateBatchAsync(
                textSegments, task.VoiceId, task.WorkingDir, task.SpeechRate);

            // Step 4: Generate video (FFmpeg)
            await UpdateStatus(task.Id, "Processing", 60, "Đang ghép video...");
            var videoRequest = BuildVideoRequest(pages, audioResults, task);
            var videoPath = await _videoService.GenerateVideoAsync(videoRequest);

            // Step 5: Generate subtitle file (.srt)
            if (task.AddSubtitles)
            {
                await UpdateStatus(task.Id, "Processing", 80, "Đang tạo phụ đề...");
                await GenerateSubtitleFile(textSegments, audioResults, task.WorkingDir);
            }

            // Step 6: Generate thumbnail
            await UpdateStatus(task.Id, "Processing", 90, "Đang tạo thumbnail...");
            var thumbnailPath = await GenerateThumbnail(videoPath);

            // Step 7: Upload + Update DB
            await UpdateStatus(task.Id, "Processing", 95, "Đang lưu file...");
            var finalUrl = await UploadToStorage(videoPath);
            
            await UpdateStatus(task.Id, "Completed", 100, "Hoàn tất!", finalUrl, thumbnailPath);
        }
        catch (Exception ex)
        {
            _logger.LogError(ex, "Video convert failed: {TaskId}", task.Id);
            await UpdateStatus(task.Id, "Failed", 0, $"Lỗi: {ex.Message}");
        }
    }
}

    -- Output

9. Output & Phân Phối Video

File output structure:

uploads/videos/{taskId}/
├── output_final.mp4          ← Video chính (1080p, H.264)
├── output_720p.mp4           ← Bản 720p (tùy chọn)
├── thumbnail.jpg             ← Ảnh thumbnail (auto-generated từ frame đầu)
├── subtitles.srt             ← File phụ đề (nếu chọn .srt riêng)
├── segments/                 ← Folder tạm (xóa sau khi xong)
│   ├── segment_000.mp4
│   ├── segment_001.mp4
│   └── ...
└── audio/                    ← Audio TTS segments
    ├── audio_000.mp3
    ├── audio_001.mp3
    └── ...

10. Tech Stack & Thư Viện

Backend (.NET 9)

  • FFmpeg — Video generation, encoding, concat
  • FFprobe — Lấy metadata audio/video duration
  • edge-tts (Python) — TTS miễn phí, Neural quality
  • BackgroundService — Worker queue xử lý nền
  • System.Diagnostics.Process — Gọi CLI tools

Frontend (Admin Portal)

  • React + Bootstrap — Form UI cấu hình
  • React Select — Dropdown chọn truyện/chương
  • ProgressBar — Hiển thị tiến độ real-time
  • Polling / SSE — Cập nhật status từ API
  • HTML5 Video — Preview video output

Cài đặt dependencies

# FFmpeg (bắt buộc):
choco install ffmpeg
# hoặc tải: ffmpeg.org/download.html

# Edge TTS (Python, bắt buộc):
pip install edge-tts

# Verify:
ffmpeg -version
edge-tts --list-voices

Yêu cầu tài nguyên

  • CPU: Nhiều core tốt hơn (FFmpeg tận dụng multi-thread)
  • RAM: ~2GB cho mỗi task convert
  • Disk: ~500MB tạm cho mỗi video (xóa sau khi xong)
  • Thời gian: ~5-10 phút cho 1 chương 15 trang (1080p)
⚠️ Lưu ý: Quá trình convert video rất tốn tài nguyên CPU. Nên giới hạn tối đa 2 tasks chạy đồng thời. Các tasks thêm vào sẽ nằm trong queue chờ.

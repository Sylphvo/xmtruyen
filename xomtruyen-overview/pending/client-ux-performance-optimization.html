1. Nguyên Tắc UX: Dễ Dùng, Không Rối

👁️

Nhìn Không Rối

Visual hierarchy rõ ràng. Mỗi trang chỉ có 1 action chính. Whitespace đủ rộng.

🖱️

Dùng Dễ Dàng

Tối đa 3 click để đến content. Nút bấm đủ lớn. Label rõ ràng. Không cần hướng dẫn.

⚡

Không Giật Lag

Response < 100ms. Scroll 60fps. Ảnh load mượt. Page transition không blank.

1.1 Quy tắc "3 giây" — First Meaningful Paint

  • < 1 giây: User cảm thấy "tức thì" → phản hồi ngay (skeleton, optimistic UI)
  • 1-3 giây: User chờ được nhưng cần feedback → loading indicator, progress bar
  • > 3 giây: User bắt đầu bực → KHÔNG BAO GIỜ cho phép trang load > 3 giây mà không có feedback

1.2 Quy tắc "Ít hơn là Nhiều hơn"

3.1 Code: Optimistic Bookmark

📁 Pattern — Click bookmark → UI đổi ngay, API chạy background
const handleBookmark = async () => {
    // 1. Optimistic: đổi UI ngay lập tức (0ms)
    setIsBookmarked(prev => !prev);
    toast.success(isBookmarked ? "Đã bỏ đánh dấu" : "Đã đánh dấu");

    try {
        // 2. API gọi background
        await toggleBookmark(chapterId);
    } catch (err) {
        // 3. Rollback nếu fail
        setIsBookmarked(prev => !prev);
        toast.error("Lỗi — đã hoàn tác");
    }
};

4. Tối Ưu Ảnh (Lazy Load, WebP, CDN)

Ảnh là bottleneck #1 của performance trên trang đọc truyện. Áp dụng:

  1. Lazy loading (native): <img loading="lazy" /> — chỉ load ảnh khi gần viewport
  2. WebP format: Convert tất cả ảnh sang WebP (giảm 25-34% so với JPEG)
  3. Responsive sizes: Serve ảnh đúng size theo device (srcset + sizes)
  4. CDN caching: Ảnh serve từ CDN edge (Cloudflare) → latency < 50ms
  5. BlurHash placeholder: Inline tiny blur ảnh (20 bytes) → hiện ngay, ảnh thật load sau
  6. Preload critical images: Cover sách trên detail page → <link rel="preload" as="image">
// Component ảnh tối ưu:
<img
    src={getImageUrl(book.coverImageUrl, 'medium')}   // 720px cho mobile
    srcSet={`
        ${getImageUrl(book.coverImageUrl, 'thumb')} 200w,
        ${getImageUrl(book.coverImageUrl, 'medium')} 720w,
        ${getImageUrl(book.coverImageUrl, 'full')} 1200w
    `}
    sizes="(max-width: 768px) 200px, 300px"
    loading="lazy"                                     // Native lazy load
    decoding="async"                                   // Non-blocking decode
    alt={book.title}
    style={{ 
        aspectRatio: '3/4',                           // Prevent layout shift
        objectFit: 'cover',
        backgroundColor: '#e5e7eb'                    // Placeholder color
    }}
/>

6. Tối Ưu React Rendering (Không Giật)

6.1 Nguyên tắc: Render ít nhất có thể

Kỹ thuậtKhi nào dùngCode
React.memo() Component nhận props không đổi nhưng parent re-render export default React.memo(BookCard)
useMemo() Tính toán nặng (sort, filter) không đổi giữa renders const sorted = useMemo(() => data.sort(...), [data])
useCallback() Function truyền xuống child memo'd component const handleClick = useCallback(() => {...}, [deps])

6.2 Anti-pattern: Tránh re-render không cần thiết

❌ Gây re-render thừa

// Object mới mỗi render → child re-render
<BookCard style={{ margin: 10 }} />

// Function mới mỗi render
<Button onClick={() => doSomething(id)} />

// Spread toàn bộ state
<Component {...state} />

✅ Tối ưu

// Constant style object
const cardStyle = { margin: 10 };
<BookCard style={cardStyle} />

// useCallback
const handleClick = useCallback(() => 
    doSomething(id), [id]);

// Chỉ pass props cần thiết
<Component title={state.title} />

7.1 SWR Pattern cho data fetch

// Pattern: Hiện data cũ ngay lập tức → fetch mới ở background → update khi xong
// Thay vì: Loading... → 2 giây → data hiện

const useBookCache = (bookId: string) => {
    const cacheKey = `book_${bookId}`;
    const [data, setData] = useState(() => {
        // 1. Trả ngay data từ cache (cũ nhưng có ngay)
        const cached = sessionStorage.getItem(cacheKey);
        return cached ? JSON.parse(cached) : null;
    });

    useEffect(() => {
        // 2. Fetch data mới ở background
        getBookDetail(bookId).then(fresh => {
            setData(fresh);
            sessionStorage.setItem(cacheKey, JSON.stringify(fresh));
        });
    }, [bookId]);

    return data; // User thấy data ngay (cũ) → update seamless khi có data mới
};

9. Mobile Performance & Touch UX

📱 Touch targets

  • Nút bấm tối thiểu 44×44px (Apple HIG)
  • Spacing giữa buttons ≥ 8px
  • Swipe areas đủ rộng (không bị tap nhầm)
  • Bottom navigation: nút quan trọng nhất ở giữa (thumb zone)

⚡ Mobile performance

  • Initial JS bundle < 200KB gzipped
  • Ảnh mobile: serve 720px max (không 1080p)
  • font-display: swap → text hiện trước, font load sau
  • Giảm DOM nodes (< 1500 per page)
  • Passive scroll listeners: { passive: true }

11. Trang Đọc Sách — UX Mượt Mà

Checklist UX mượt cho Reading Page:

  1. Không layout shift: Content area có chiều cao cố định hoặc aspect-ratio — không nhảy khi ảnh load
  2. Preload chương tiếp: Khi đọc > 80% chương → fetch chương tiếp ở background
  3. Seamless chapter transition: Cuộn hết chương → auto load chương tiếp (không reload page)
  4. Instant mode switch: Đổi theme/font/size → transition smooth 200ms (không flash trắng)
  5. Keep screen on: navigator.wakeLock.request('screen') — màn hình không tắt khi đọc
  6. Auto-save position: Mỗi 10 giây → lưu % đọc → resume khi quay lại
  7. Toolbar ẩn/hiện: Khi đọc → toolbar biến mất (full immersion). Tap/cuộn lên → hiện lại.
  8. Keyboard/gesture responsive: Phím tắt + swipe phản hồi < 100ms
  9. Offline ready: Chương đã load cache trong memory → đọc lại không cần fetch
  10. Error graceful: Ảnh 404 → placeholder "Ảnh lỗi — tap thử lại" (không ảnh broken icon xấu)

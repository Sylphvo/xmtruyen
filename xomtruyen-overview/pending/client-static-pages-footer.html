3. Trang "Về Chúng Tôi" (/about)

Nội dung trang Giới thiệu:

  • Hero banner với slogan
  • Sứ mệnh & Tầm nhìn
  • Con số ấn tượng (số sách, số user, số chương...)
  • Đội ngũ (nếu muốn hiện)
  • Timeline phát triển
  • Đối tác / NXB hợp tác

4. Trang "Thỏa Thuận Sử Dụng Dịch Vụ" (/terms)

Cấu trúc nội dung Điều khoản:

  1. Định nghĩa thuật ngữ
  2. Phạm vi áp dụng
  3. Đăng ký tài khoản & quyền truy cập
  4. Quy tắc sử dụng dịch vụ (không sao chép, không phân phối lại...)
  5. Nội dung người dùng đăng tải (reviews, comments)
  6. Sở hữu trí tuệ & bản quyền
  7. Thanh toán & gói dịch vụ
  8. Giới hạn trách nhiệm
  9. Chấm dứt tài khoản
  10. Luật áp dụng & giải quyết tranh chấp
  11. Thay đổi điều khoản

5. Trang "Quy Định Riêng Tư" (/privacy)

Cấu trúc Privacy Policy:

  1. Thông tin thu thập (email, tên, lịch sử đọc, IP...)
  2. Mục đích thu thập
  3. Chia sẻ thông tin với bên thứ ba
  4. Bảo mật dữ liệu (mã hóa, JWT, HTTPS)
  5. Cookie & tracking
  6. Quyền của người dùng (xem, sửa, xóa dữ liệu cá nhân)
  7. Lưu trữ & thời gian giữ dữ liệu
  8. Thay đổi chính sách
  9. Liên hệ bộ phận bảo mật

7. Trang "Chính Sách Đổi Trả / Thanh Toán"

Nội dung chính sách:

  • Phương thức thanh toán: VNPay, MoMo, chuyển khoản ngân hàng, thẻ quốc tế
  • Mua xu: Bảng giá xu (VD: 50K = 100 xu, 100K = 220 xu...)
  • Gói VIP: Tháng / Quý / Năm — giá + quyền lợi
  • Hoàn xu: Điều kiện hoàn (mua nhầm chương, lỗi kỹ thuật). Thời hạn yêu cầu hoàn: 7 ngày.
  • Hủy VIP: Quy trình hủy, thời điểm có hiệu lực, hoàn tiền tỷ lệ
  • Bảo mật thanh toán: SSL, không lưu thẻ, PCI DSS compliance

11. Quản Lý Nội Dung Tĩnh (Admin CMS)

Vấn đề: Nội dung các trang tĩnh (Terms, Privacy, FAQ...) cần thay đổi thường xuyên mà không cần deploy lại code. → Cần CMS đơn giản trong Admin để quản lý.

Giải pháp: Trang "Quản Lý Nội Dung" trong Admin Portal

  • Admin trang: /admin/static-pages
  • CRUD: Tạo/sửa/xóa trang tĩnh
  • Rich text editor: Soạn nội dung HTML (tiêu đề, đoạn văn, list, link, ảnh)
  • SEO fields: Meta title, meta description, slug
  • Publish/Draft: Lưu nháp trước khi xuất bản
  • API: GET /api/pages/{slug} → client fetch content động

11.1 Database Schema

CREATE TABLE "StaticPages" (
    "Id" UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    "Slug" VARCHAR(100) UNIQUE NOT NULL,      -- 'terms', 'privacy', 'faq', 'about'
    "Title" VARCHAR(200) NOT NULL,             -- Tiêu đề hiển thị
    "Content" TEXT NOT NULL,                   -- HTML content (rich text)
    "MetaTitle" VARCHAR(200),                  -- SEO title
    "MetaDescription" VARCHAR(500),            -- SEO description
    "Status" VARCHAR(20) DEFAULT 'Published', -- 'Published' | 'Draft'
    "UpdatedBy" UUID,
    "CreatedAt" TIMESTAMPTZ DEFAULT NOW(),
    "UpdatedAt" TIMESTAMPTZ DEFAULT NOW()
);

-- FAQ riêng (structured data):
CREATE TABLE "FaqItems" (
    "Id" UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    "Category" VARCHAR(50) NOT NULL,           -- 'account', 'reading', 'payment', 'vip'
    "Question" TEXT NOT NULL,
    "Answer" TEXT NOT NULL,
    "OrderIndex" INT DEFAULT 0,
    "IsActive" BOOLEAN DEFAULT TRUE,
    "CreatedAt" TIMESTAMPTZ DEFAULT NOW()
);

12.1 Generic Static Page Component

📁 xom-truyen/src/pages/static/StaticPage.tsx
import React, { useState, useEffect } from 'react';
import { useParams } from 'react-router-dom';
import axios from 'axios';

/**
 * Generic component cho tất cả trang tĩnh.
 * Fetch nội dung từ API theo slug → render HTML.
 */
export default function StaticPage() {
    const { slug } = useParams<{ slug: string }>();
    const [page, setPage] = useState<{ title: string; content: string } | null>(null);
    const [loading, setLoading] = useState(true);

    useEffect(() => {
        setLoading(true);
        axios.get(`/api/pages/${slug}`)
            .then(res => setPage(res.data))
            .catch(() => setPage(null))
            .finally(() => setLoading(false));
    }, [slug]);

    if (loading) return <div style={{ padding: 60, textAlign: 'center' }}>Đang tải...</div>;
    if (!page) return <div style={{ padding: 60, textAlign: 'center' }}>Trang không tồn tại</div>;

    return (
        <div style={{ maxWidth: 800, margin: '0 auto', padding: '40px 20px' }}>
            <h1 style={{ fontSize: 28, fontWeight: 700, marginBottom: 24 }}>{page.title}</h1>
            <div 
                className="static-page-content"
                style={{ fontSize: 15, lineHeight: 1.8, color: '#374151' }}
                dangerouslySetInnerHTML={{ __html: page.content }}
            />
        </div>
    );
}

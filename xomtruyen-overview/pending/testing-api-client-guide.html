8.2 Script chạy test API tự động (Postman Collection Runner)

📁 xomtruyen-overview/test-api-collection.json (Postman format)
// Cách sử dụng:
// 1. Import file JSON vào Postman
// 2. Set environment variable: {{BASE_URL}} = http://localhost:5000
// 3. Chạy Collection Runner → tất cả test cases chạy tự động
// 4. Xem report → export kết quả

// Ví dụ 1 request trong collection:
{
    "name": "AUTH-03: Login thành công",
    "request": {
        "method": "POST",
        "url": "{{BASE_URL}}/api/auth/login",
        "body": {
            "mode": "raw",
            "raw": "{\"email\":\"admin@xomtruyen.com\",\"password\":\"Admin123!\"}"
        }
    },
    "event": [{
        "listen": "test",
        "script": {
            "exec": [
                "pm.test('Status 200', () => pm.response.to.have.status(200));",
                "pm.test('Has token', () => {",
                "    const json = pm.response.json();",
                "    pm.expect(json.data.token).to.be.a('string');",
                "    pm.environment.set('AUTH_TOKEN', json.data.token);",
                "});"
            ]
        }
    }]
}

15.3 Cách sử dụng

  1. Trước khi test: Copy template JSON, đổi ngày + tên tester
  2. Trong khi test: Mỗi test case → ghi status (PASS/FAIL/SKIP). Nếu FAIL → thêm entry vào mảng bugs
  3. Sau khi test: Update summary counts. Gửi file JSON cho developer
  4. Developer fix: Cập nhật status: "Fixed", fixedAt: "2026-08-XX"
  5. Re-test: Chạy lại test case đã fix → đổi status thành "Verified" hoặc "Reopened"
💡 Tip: Tạo thư mục xomtruyen-overview/test-results/ để lưu tất cả file JSON kết quả test. Mỗi lần test mới → tạo file mới với ngày (vd: bug-log-api-2026-08-17.json).

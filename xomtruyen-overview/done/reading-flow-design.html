3.1 Tính năng Comic Reader

Đã có ✅

  • Load ảnh cuộn dọc (webtoon style)
  • Lazy loading images (loading="lazy")
  • Chuyển chương (Trước/Sau)
  • Header hiển thị tên truyện
  • Hiển thị số chương hiện tại / tổng

Cần bổ sung 🆕

  • Đổi CDN server (Server 1 / Server 2)
  • Zoom pinch-to-zoom (mobile)
  • Chế độ lật trang (page-by-page) ngoài cuộn dọc
  • Preload 3 trang tiếp theo
  • Chế độ toàn màn hình (fullscreen)
  • Slider nhảy nhanh đến trang X
  • Đổi nền (sáng/tối) cho viền ảnh

4.1 Tính năng Text Reader

Đã có ✅

  • Hiển thị nội dung text/HTML
  • Chuyển chương (mũi tên trái/phải)
  • Header hiển thị tên truyện
  • Footer hiển thị vị trí chương
  • Max-width giới hạn dễ đọc

Cần bổ sung 🆕

  • Tăng/giảm cỡ chữ (A- / A+)
  • Đổi font chữ (Roboto, Literata, Merriweather)
  • Đổi theme (Sáng / Tối / Sepia)
  • Điều chỉnh line-height
  • Cuộn tự động (auto-scroll với tốc độ tùy chỉnh)
  • Lưu vị trí đọc (scroll %) → resume
  • Chế độ toàn màn hình
  • Ước tính thời gian đọc còn lại

10. Data Flow (API ↔ Client)

┌─────────────────────────────────────────────────────────────────────────────┐ │ DATA FLOW: Client ↔ API ↔ Database │ └─────────────────────────────────────────────────────────────────────────────┘ ① User mở /read/{bookId} │ ├──▶ GET /api/Publications/{bookId} │ → { title, formatType, ... } │ ├──▶ GET /api/comic-chapters?publicationId={bookId} (if comic) │ → [{ id, title, chapterNumber, orderIndex }] │ HOẶC ├──▶ GET /api/text-chapters?publicationId={bookId} (if text) │ → [{ id, title, chapterNumber, content }] │ ② User click chương / auto-load chương đầu │ ├──▶ GET /api/reading/chapter/{chapterId} │ → Comic: { imageUrls: ["url1", "url2", ...] } │ → Text: { content: "HTML string..." } │ → Locked: { isLocked: true, unlockPrice: 5 } │ ③ Tracking (gửi ngầm) │ ├──▶ POST /api/engagement/history │ → { publicationId, chapterId, chapterType } │ ├──▶ POST /api/Publications/{bookId}/view │ → increment view count │ ④ User bookmark │ ├──▶ POST /api/bookmarks/toggle │ → { chapterId, chapterType } │ ← { message: "Added bookmark" | "Removed bookmark" } │ ⑤ User mua chương VIP │ ├──▶ POST /api/reading/purchase/{chapterId} │ ← { success: true } → reload content │ ← { success: false } → redirect /wallet │ ⑥ Lưu tiến độ (auto, mỗi 30 giây) │ └──▶ POST /api/reading/progress → { chapterId, scrollPercent, lastPosition }
💡 Tóm tắt: ReadingPage.tsx là controller chính — phân loại nội dung (comic/text), quản lý chapters navigation, gọi API, và render đúng component con. Tất cả controls (bookmark, mode toggle, chapter nav) đều nằm ở page level và truyền xuống components qua props.

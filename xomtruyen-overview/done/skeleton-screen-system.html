1. Tổng Quan & Nguyên Tắc Thiết Kế

1.1 Tại sao Skeleton Screen?

❌ Hiện tại (Spinner / Blank)

  • Spinner xoay tròn → user không biết content sẽ có gì
  • Trang trắng → cảm giác chậm, CLS (Cumulative Layout Shift) cao
  • Text "Đang tải..." → boring, thiếu chuyên nghiệp

✅ Mới (Skeleton Screen)

  • Hiển thị "hình dạng" nội dung sắp tới → user biết trước layout
  • Animation shimmer → cảm giác đang load nhanh
  • Không layout shift (CLS = 0) vì skeleton chiếm đúng diện tích content
  • Perceived performance tốt hơn 40% (theo UX research)

1.2 Nguyên tắc thiết kế

  1. Match layout thực tế: Skeleton phải chiếm đúng kích thước / vị trí của content thật
  2. Không quá chi tiết: Dùng hình chữ nhật / hình tròn đơn giản, KHÔNG skeleton từng chữ
  3. Animation nhất quán: Toàn hệ thống dùng 1 kiểu shimmer (trái → phải, 1.5s loop)
  4. Transition mượt: Khi data load xong → fade-in content, fade-out skeleton (200ms)
  5. Số lượng hợp lý: Hiện 3-6 skeleton items, không hiện 50 skeleton rows

2.1 SkeletonBone — Primitive cơ bản

📁 src/components/Skeleton/SkeletonBone.tsx (dùng chung cả 3 app)
import React from 'react';
import './Skeleton.scss';

interface SkeletonBoneProps {
    /** Chiều rộng (px, %, hoặc 'full') */
    width?: string | number;
    /** Chiều cao (px) */
    height?: string | number;
    /** Hình dạng */
    variant?: 'text' | 'circular' | 'rectangular' | 'rounded';
    /** Class bổ sung */
    className?: string;
    /** Inline style bổ sung */
    style?: React.CSSProperties;
}

export const SkeletonBone: React.FC<SkeletonBoneProps> = ({
    width = '100%',
    height = 16,
    variant = 'text',
    className = '',
    style = {}
}) => {
    const variantClass = {
        text: 'skeleton-text',
        circular: 'skeleton-circular',
        rectangular: 'skeleton-rectangular',
        rounded: 'skeleton-rounded',
    }[variant];

    return (
        <div
            className={`skeleton-bone ${variantClass} ${className}`}
            style={{
                width: typeof width === 'number' ? `${width}px` : width,
                height: typeof height === 'number' ? `${height}px` : height,
                ...style
            }}
            aria-hidden="true"
            role="presentation"
        />
    );
};

    direction = 'column',
    children,
    className = ''

            className={`skeleton-group ${className}`}

};

2.3 SkeletonWrapper — Container với fade transition

📁 src/components/Skeleton/SkeletonWrapper.tsx
import React, { useEffect, useState } from 'react';

interface SkeletonWrapperProps {
    /** Đang loading hay không */
    isLoading: boolean;
    /** Skeleton hiển thị khi loading */
    skeleton: React.ReactNode;
    /** Content thật hiển thị khi load xong */
    children: React.ReactNode;
    /** Thời gian transition (ms) */
    fadeDuration?: number;
    /** Delay tối thiểu hiển thị skeleton (tránh flash) */
    minDisplayTime?: number;
}

export const SkeletonWrapper: React.FC<SkeletonWrapperProps> = ({
    isLoading,
    skeleton,
    children,
    fadeDuration = 200,
    minDisplayTime = 300
}) => {
    const [showSkeleton, setShowSkeleton] = useState(isLoading);
    const [isTransitioning, setIsTransitioning] = useState(false);

    useEffect(() => {
        if (isLoading) {
            setShowSkeleton(true);
            setIsTransitioning(false);
        } else {
            // Đảm bảo skeleton hiển thị tối thiểu minDisplayTime ms
            const timer = setTimeout(() => {
                setIsTransitioning(true);
                setTimeout(() => {
                    setShowSkeleton(false);
                    setIsTransitioning(false);
                }, fadeDuration);
            }, minDisplayTime);
            return () => clearTimeout(timer);
        }
    }, [isLoading, fadeDuration, minDisplayTime]);

    if (!showSkeleton) {
        return (
            <div className="skeleton-content-enter" style={{ animation: `fadeIn ${fadeDuration}ms ease` }}>
                {children}
            </div>
        );
    }

    return (
        <div className={`skeleton-container ${isTransitioning ? 'skeleton-fade-out' : ''}`}
             style={{ transition: `opacity ${fadeDuration}ms ease`, opacity: isTransitioning ? 0 : 1 }}>
            {skeleton}
        </div>
    );
};

6. Custom Hook: useSkeleton

📁 src/hooks/useSkeleton.ts (dùng chung)
import { useState, useEffect, useRef } from 'react';

interface UseSkeletonOptions {
    /** Đang loading */
    isLoading: boolean;
    /** Thời gian tối thiểu hiển thị skeleton (ms) — tránh flash */
    minDisplayTime?: number;
    /** Delay trước khi hiện skeleton (ms) — nếu load < delay thì không hiện skeleton */
    delay?: number;
}

/**
 * Hook quản lý trạng thái hiển thị skeleton.
 * - Tránh flash skeleton (hiện rồi biến mất ngay nếu load nhanh)
 * - Đảm bảo skeleton hiển thị tối thiểu N ms (tránh giật)
 */
export function useSkeleton({ isLoading, minDisplayTime = 400, delay = 100 }: UseSkeletonOptions) {
    const [showSkeleton, setShowSkeleton] = useState(false);
    const loadStartRef = useRef<number>(0);
    const delayTimerRef = useRef<NodeJS.Timeout>();

    useEffect(() => {
        if (isLoading) {
            loadStartRef.current = Date.now();

            // Chỉ hiện skeleton nếu loading kéo dài hơn `delay` ms
            delayTimerRef.current = setTimeout(() => {
                setShowSkeleton(true);
            }, delay);
        } else {
            // Clear delay timer nếu load xong trước khi skeleton hiện
            if (delayTimerRef.current) {
                clearTimeout(delayTimerRef.current);
            }

            if (showSkeleton) {
                // Đảm bảo skeleton hiển thị tối thiểu minDisplayTime
                const elapsed = Date.now() - loadStartRef.current;
                const remaining = Math.max(0, minDisplayTime - elapsed);

                setTimeout(() => {
                    setShowSkeleton(false);
                }, remaining);
            }
        }

        return () => {
            if (delayTimerRef.current) clearTimeout(delayTimerRef.current);
        };
    }, [isLoading]);

    return { showSkeleton };
}

6.1 Cách sử dụng

// Trong component bất kỳ:
const { showSkeleton } = useSkeleton({ isLoading, minDisplayTime: 400, delay: 100 });

return showSkeleton
    ? <TableSkeleton rows={5} columns={6} />
    : <ActualTable data={data} />;
Hành vi:
  • Nếu API trả về trong <100ms → KHÔNG hiện skeleton (tránh flash)
  • Nếu API chậm >100ms → hiện skeleton, giữ tối thiểu 400ms (tránh giật)
  • Kết quả: UX mượt, không bao giờ thấy skeleton "nháy" quá nhanh

8. CSS / SCSS Animation System

// ═══════════════════════════════════════════
// SKELETON SCREEN — Animation System
// ═══════════════════════════════════════════

// Variables
$skeleton-bg: var(--skeleton-bg, #2a2a3e);
$skeleton-highlight: var(--skeleton-highlight, #3a3a4e);
$skeleton-radius: 4px;
$skeleton-animation-duration: 1.5s;

// Base bone style
.skeleton-bone {
    background: linear-gradient(
        90deg,
        $skeleton-bg 25%,
        $skeleton-highlight 50%,
        $skeleton-bg 75%
    );
    background-size: 200% 100%;
    animation: skeletonShimmer $skeleton-animation-duration infinite ease-in-out;
    border-radius: $skeleton-radius;
}

// Variants
.skeleton-text {
    border-radius: $skeleton-radius;
}

.skeleton-circular {
    border-radius: 50%;
}

.skeleton-rectangular {
    border-radius: 0;
}

.skeleton-rounded {
    border-radius: 8px;
}

// Shimmer animation
@keyframes skeletonShimmer {
    0% { background-position: 200% 0; }
    100% { background-position: -200% 0; }
}

// Fade transitions
.skeleton-fade-out {
    opacity: 0;
    transition: opacity 200ms ease;
}

@keyframes fadeIn {
    from { opacity: 0; }
    to { opacity: 1; }

10. Hướng Dẫn Migration

10.1 Checklist cho mỗi trang (3 bước)

  1. Import skeleton: Import component phù hợp (TableSkeleton, BookGridSkeleton...)
  2. Thay thế loading state: Thay {isLoading && "Đang tải..."} bằng {showSkeleton && <TableSkeleton />}
  3. Wrap content: Hoặc dùng <SkeletonWrapper> để tự động fade transition

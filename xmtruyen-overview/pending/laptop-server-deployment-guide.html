3. Cài Đặt & Cấu Hình PostgreSQL

1 Cài đặt PostgreSQL

# Tải installer từ: https://www.postgresql.org/download/windows/
# Chạy installer, chọn:
#   - Port: 5432 (default)
#   - Password cho user 'postgres': đặt mật khẩu mạnh
#   - Locale: Vietnamese hoặc English
#   - Tick: pgAdmin 4 (để quản lý qua GUI)

2 Tạo Database

# Mở Command Prompt hoặc psql:
psql -U postgres

# Tạo database:
CREATE DATABASE xmtruyen_db;

# Tạo user riêng (khuyến nghị):
CREATE USER xmtruyen_user WITH PASSWORD 'YourStrongPassword123!';
GRANT ALL PRIVILEGES ON DATABASE xmtruyen_db TO xmtruyen_user;
ALTER USER xmtruyen_user CREATEDB;

# Thoát:
\q

3 Cấu hình cho phép kết nối từ xa (nếu cần)

📁 C:\Program Files\PostgreSQL\16\data\postgresql.conf
# Tìm dòng listen_addresses và sửa:
listen_addresses = '*'    # Cho phép kết nối từ mọi IP (hoặc chỉ định IP cụ thể)
📁 C:\Program Files\PostgreSQL\16\data\pg_hba.conf (thêm dòng cuối)
# Cho phép kết nối từ mạng LAN (ví dụ 192.168.1.0/24)
host    all    all    192.168.1.0/24    scram-sha-256

# Hoặc cho phép tất cả (KHÔNG khuyến nghị cho production):
# host    all    all    0.0.0.0/0    scram-sha-256

4 Khởi động lại PostgreSQL service

# Mở Services (Win+R → services.msc)
# Tìm "postgresql-x64-16" → Restart

# Hoặc CMD (Admin):
net stop postgresql-x64-16
net start postgresql-x64-16

5 Kiểm tra kết nối

psql -U xmtruyen_user -d xmtruyen_db -h localhost
# Nếu thấy prompt "xmtruyen_db=>" → OK

7. Cấu Hình Reverse Proxy (Nginx)

1 Cài đặt Nginx for Windows

# Tải: http://nginx.org/en/download.html (Windows stable)
# Giải nén vào: D:\tools\nginx\

# Test khởi động:
cd D:\tools\nginx
nginx.exe

# Mở http://localhost → thấy "Welcome to nginx!" → OK
# Dừng: nginx.exe -s stop

2 Cấu hình nginx.conf

📁 D:\tools\nginx\conf\nginx.conf
worker_processes  auto;

events {
    worker_connections  1024;
}

http {
    include       mime.types;
    default_type  application/octet-stream;
    sendfile      on;
    keepalive_timeout  65;
    client_max_body_size 500M;  # Cho phép upload file lớn

    # ═══════════════════════════════════════════
    # WEB CLIENT — Port 80 (hoặc domain chính)
    # ═══════════════════════════════════════════
    server {
        listen       80;
        server_name  localhost 192.168.1.100;

        # Web Client (React SPA)
        location / {
            root   D:/deploy/www/web-client;
            index  index.html;
            try_files $uri $uri/ /index.html;  # SPA routing fallback
        }

        # API Proxy — forward /api requests to .NET backend
        location /api/ {
            proxy_pass http://127.0.0.1:5000/api/;
            proxy_http_version 1.1;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_set_header X-Forwarded-Proto $scheme;
            proxy_read_timeout 300s;
            proxy_send_timeout 300s;
        }

        # Uploads — serve static uploaded files
        location /uploads/ {
            alias D:/deploy/xmtruyen/uploads/;
            expires 30d;
            add_header Cache-Control "public, immutable";
        }
    }

    # ═══════════════════════════════════════════
    # ADMIN PORTAL — Port 3001
    # ═══════════════════════════════════════════
    server {
        listen       3001;
        server_name  localhost 192.168.1.100;

        # Admin Portal (React SPA)
        location / {
            root   D:/deploy/www/admin-portal;
            index  index.html;
            try_files $uri $uri/ /index.html;
        }

        # API Proxy
        location /api/ {
            proxy_pass http://127.0.0.1:5000/api/;
            proxy_http_version 1.1;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
            proxy_read_timeout 300s;
        }

        # Uploads
        location /uploads/ {
            alias D:/deploy/xmtruyen/uploads/;
        }
    }

    # ═══════════════════════════════════════════
    # API TRỰC TIẾP — Port 5000 (optional, dev)
    # ═══════════════════════════════════════════
    # API đã chạy trực tiếp trên port 5000 qua Kestrel
    # Không cần Nginx proxy nếu truy cập trực tiếp
}

8. Mở Port & Cấu Hình Firewall Windows

1 Mở ports qua PowerShell (Admin)

# Mở PowerShell với quyền Administrator:

# Port 80 (Web Client qua Nginx):
New-NetFirewallRule -DisplayName "Xmtruyen Web (HTTP)" -Direction Inbound -Protocol TCP -LocalPort 80 -Action Allow

# Port 443 (HTTPS - nếu dùng SSL):
New-NetFirewallRule -DisplayName "Xmtruyen Web (HTTPS)" -Direction Inbound -Protocol TCP -LocalPort 443 -Action Allow

# Port 3001 (Admin Portal):
New-NetFirewallRule -DisplayName "Xmtruyen Admin" -Direction Inbound -Protocol TCP -LocalPort 3001 -Action Allow

# Port 5000 (API trực tiếp - tùy chọn):
New-NetFirewallRule -DisplayName "Xmtruyen API" -Direction Inbound -Protocol TCP -LocalPort 5000 -Action Allow

# Port 5432 (PostgreSQL remote - CHỈ nếu cần):
# New-NetFirewallRule -DisplayName "PostgreSQL" -Direction Inbound -Protocol TCP -LocalPort 5432 -Action Allow

2 Kiểm tra Firewall

# Liệt kê rules đã tạo:
Get-NetFirewallRule -DisplayName "Xmtruyen*" | Format-Table DisplayName, Enabled, Direction

# Test từ máy khác trong LAN:
# Trên máy khác: mở trình duyệt → http://192.168.1.100
# Phải thấy Web Client

3 Tắt Windows Defender Firewall (nếu vẫn bị chặn)

⚠️ Không khuyến nghị: Chỉ tắt tạm để test. Sau đó bật lại và chỉ mở đúng ports cần thiết.

Set-NetFirewallProfile -Profile Domain,Public,Private -Enabled False

# Bật lại:
Set-NetFirewallProfile -Profile Domain,Public,Private -Enabled True

9. Domain & HTTPS (Tùy Chọn)

9.1 Truy cập qua mạng LAN (không cần domain)

Nếu chỉ dùng trong mạng nội bộ:

  • Web Client: http://192.168.1.100
  • Admin: http://192.168.1.100:3001
  • API: http://192.168.1.100:5000/scalar/v1

Không cần domain, không cần HTTPS.

9.2 Truy cập từ Internet (cần domain + DDNS)

# Bước 1: Đăng ký Dynamic DNS (miễn phí)
#   - noip.com
#   - duckdns.org
#   - freedns.afraid.org
# Ví dụ: xmtruyen.duckdns.org → trỏ về IP công cộng của bạn

# Bước 2: Port forwarding trên Router
#   - Vào trang quản trị router (thường 192.168.1.1)
#   - Port Forwarding:
#     External Port 80 → Internal 192.168.1.100:80
#     External Port 443 → Internal 192.168.1.100:443

# Bước 3: Kiểm tra IP công cộng
curl ifconfig.me

9.3 HTTPS với Let's Encrypt (win-acme)

# Tải win-acme: https://www.win-acme.com/
# Giải nén vào D:\tools\win-acme\

# Chạy:
D:\tools\win-acme\wacs.exe

# Chọn:
#   N: Create certificate (default settings)
#   → Nhập domain: xmtruyen.duckdns.org
#   → Chọn: Save to path
#   → Path: D:\tools\nginx\ssl\
#   → Auto-renew: Yes
📁 nginx.conf — Thêm HTTPS server block
server {
    listen       443 ssl;
    server_name  xmtruyen.duckdns.org;

    ssl_certificate      D:/tools/nginx/ssl/xmtruyen.duckdns.org-chain.pem;
    ssl_certificate_key  D:/tools/nginx/ssl/xmtruyen.duckdns.org-key.pem;

    # ... giữ nguyên location blocks từ server port 80 ...
}

# Redirect HTTP → HTTPS
server {
    listen 80;
    server_name xmtruyen.duckdns.org;
    return 301 https://$host$request_uri;
}

12. Xử Lý Sự Cố Thường Gặp

Triệu chứngNguyên nhânCách khắc phục
Truy cập http://IP → timeout Firewall chặn port 80 Chạy lại lệnh New-NetFirewallRule (mục 8)
Web Client hiện blank / 404 Thiếu try_files trong nginx.conf Thêm try_files $uri $uri/ /index.html;
API trả về 500 Internal Server Error Connection string sai hoặc DB chưa migrate Kiểm tra appsettings.Production.json + chạy dotnet ef database update
CORS error trên browser IP client không nằm trong AllowedOrigins Thêm IP/domain vào appsettings.Production.json → restart API
Upload file lỗi 413 (Request Entity Too Large) Nginx giới hạn body size Thêm client_max_body_size 500M; vào nginx.conf
Ảnh/video không load (404) Đường dẫn uploads sai Kiểm tra location /uploads/ trỏ đúng thư mục có file
API service tự dừng sau vài giờ Kestrel crash, NSSM không restart NSSM → Edit XmtruyenAPI → tab "Exit actions" → chọn "Restart"
Không truy cập được từ Internet Router chưa port forward Cấu hình port forwarding trên router (mục 9.2)
PostgreSQL từ chối kết nối Service chưa start hoặc pg_hba.conf thiếu rule Kiểm tra service + thêm rule vào pg_hba.conf (mục 3)

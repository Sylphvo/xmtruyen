🎙️ 1. Tổng quan Audiobook Pipeline

Mục tiêu

Biến toàn bộ nội dung truyện (chữ + tranh) thành sách nói. User có thể nghe truyện thay vì đọc — phục vụ khi lái xe, tập gym, trước khi ngủ. Mở rộng thêm format FormatType = Audio (2) đã có sẵn trong model Publication.

📚 2. Nguồn nội dung để convert

NguồnLoạiCách lấy textChất lượng audioEffort

B. ComicChapter (Truyện tranh đã dịch) Text từ TextBlocks (OCR + translated) Ghép TextBlocks theo order → tạo script Trung bình — dialog ngắn, thiếu narration Trung bình

💡 Khuyến nghị

Bắt đầu với nguồn A (Truyện chữ) — dễ nhất, chất lượng cao nhất. Sau đó mở rộng sang nguồn B (Comic đã dịch) khi pipeline ổn định. Nguồn E (upload audio thật) luôn hỗ trợ song song cho trường hợp thuê người đọc.

📖 3. Luồng A: Convert từ truyện chữ (BookChapter → Audio)

┌──────────────────────────────────────────────────────────────────────┐ │ LUỒNG A: TRUYỆN CHỮ → SÁCH NÓI │ ├──────────────────────────────────────────────────────────────────────┤ │ │ │ 1. ADMIN CHỌN NGUỒN │ │ └── Chọn Publication (FormatType=Text) + Chapter range │ │ └── System lấy BookChapter.Content từ DB │ │ │ │ 2. TEXT PREPROCESSING │ │ ├── Strip HTML tags (giữ paragraph breaks) │ │ ├── Detect dialog vs narration: │ │ │ • "text trong ngoặc kép" → Dialog (voice: character) │ │ │ • Text ngoài → Narration (voice: narrator) │ │ ├── Split thành segments (~200-500 chars mỗi segment) │ │ ├── Assign voice per segment: │ │ │ • Narrator segments → voice_narrator │ │ │ • Dialog (nam) → voice_male_01 │ │ │ • Dialog (nữ) → voice_female_01 │ │ ├── Add SSML markers: │ │ │ • giữa paragraphs │ │ │ • cho dialog quan trọng │ │ │ • cho internal thoughts │ │ └── Output: AudioScript (JSON array of segments) │ │ │ │ 3. TTS GENERATION │ │ ├── For each segment: │ │ │ • Call TTS API (voice=segment.voice, text=segment.text) │ │ │ • Receive: audio chunk (WAV/MP3) │ │ │ • Store chunk: /audio/chunks/{jobId}/seg_{001}.mp3 │ │ └── Progress tracking: x/total segments done │ │ │ │ 4. AUDIO POST-PROCESSING │ │ ├── Concatenate all chunks → full chapter audio │ │ ├── Normalize volume (loudness -16 LUFS) │ │ ├── Add silence padding (0.5s start, 1s end) │ │ ├── (Optional) Add background music (low volume, looping) │ │ ├── Export: MP3 128kbps / M4A AAC │ │ └── Generate waveform data (for player visualization) │ │ │ │ 5. QC REVIEW │ │ ├── Admin nghe thử trên player │ │ ├── Timestamp issues: "phút 3:24 phát âm sai 'kiếm khí'" │ │ ├── Re-generate segment cụ thể (sửa text hoặc đổi voice) │ │ └── Approve / Reject │ │ │ │ 6. PUBLISH │ │ ├── Create AudioChapter record │ │ ├── Upload final MP3 to storage │ │ ├── Set metadata: duration, fileSize, isLocked, coinPrice │ │ └── Notify users │ │ │ └──────────────────────────────────────────────────────────────────────┘

🖼️ 4. Luồng B: Convert từ truyện tranh (Comic → Audio)

┌──────────────────────────────────────────────────────────────────────┐ │ LUỒNG B: TRUYỆN TRANH → SÁCH NÓI │ ├──────────────────────────────────────────────────────────────────────┤ │ │ │ NGUỒN TEXT: Lấy từ TextBlocks (Translation Pipeline) │ │ ┌────────────────────────────────────────────────────────┐ │ │ │ TextBlocks (đã dịch) per page: │ │ │ │ • block_001: "Ngươi dám!" (dialog, character A) │ │ │ │ • block_002: "ĐÙNG!" (sfx) │ │ │ │ • block_003: "Hắn ngã xuống" (narration) │ │ │ └────────────────────────────────────────────────────────┘ │ │ │ │ 1. EXTRACT & BUILD SCRIPT │ │ ├── Lấy tất cả TextBlocks của chapter (sorted by page + order) │ │ ├── Filter: bỏ SFX blocks (hoặc convert SFX → sound effects) │ │ ├── Classify: │ │ │ • textType="dialog" → Giọng nhân vật │ │ │ • textType="narration" → Giọng narrator │ │ │ • textType="sfx" → SFX sound effect file (optional) │ │ ├── Add transitions giữa pages: │ │ │ "--- Trang tiếp theo ---" hoặc pause 1.5s │ │ └── Output: AudioScript (giống luồng A) │ │ │ │ 2. (OPTIONAL) AI EXPAND NARRATION │ │ ├── Comic dialog thường rất ngắn, thiếu mô tả │ │ ├── Dùng AI để thêm narration mô tả cảnh: │ │ │ Prompt: "Given these manga dialogs, add brief narration │ │ │ describing the scene between dialogs" │ │ │ Input: ["Ngươi dám!", "Ta sẽ giết ngươi!"] │ │ │ Output: "Lâm Phong nắm chặt kiếm, mắt đỏ ngầu..." │ │ └── Kết quả: Script dài hơn, nghe mạch lạc hơn │ │ │ │ 3-6: GIỐNG LUỒNG A (TTS → Post-process → QC → Publish) │ │ │ └──────────────────────────────────────────────────────────────────────┘

Thách thức khi convert Comic → Audio

Vấn đềGiải pháp
Dialog quá ngắn, không đủ context để nghe AI expand narration — thêm mô tả cảnh giữa các dialog
Không biết ai nói (nhiều nhân vật trong 1 trang) AI detect speaker từ context, hoặc admin tag manual. Default: alternate male/female voices
SFX (hiệu ứng âm thanh) — "ĐÙNG!", "XOẸT!" Map SFX text → pre-recorded sound effect files (explosion.mp3, sword.mp3). Hoặc bỏ qua SFX
Reading order không rõ (manga đọc phải→trái) Dùng TextBlocks.OrderIndex (đã set đúng khi OCR/translate)
Audio quá ngắn (1 page comic = 5-10 giây audio) Ghép nhiều pages thành 1 audio segment dài hơn. Thêm pause giữa scenes

Edge TTS (Free) — Setup nhanh

# Python: pip install edge-tts

import edge_tts
import asyncio

async def text_to_speech(text: str, voice: str, output_path: str):
    """
    Vietnamese voices available:
    - vi-VN-HoaiMyNeural (female, clear)
    - vi-VN-NamMinhNeural (male, deep)
    """
    communicate = edge_tts.Communicate(text, voice)
    await communicate.save(output_path)

# Usage:
asyncio.run(text_to_speech(
    text="Lâm Phong cầm kiếm, nội lực vận chuyển khắp cơ thể.",
    voice="vi-VN-NamMinhNeural",
    output_path="output.mp3"
))

Google Cloud TTS — Với SSML control

# Python: pip install google-cloud-texttospeech

from google.cloud import texttospeech

def generate_speech(text: str, voice_name: str, output_path: str):
    client = texttospeech.TextToSpeechClient()
    
    # SSML cho control emotion/pause
    ssml = f"""
    
        
            {text}
        
        
    
    """
    
    input_text = texttospeech.SynthesisInput(ssml=ssml)
    voice = texttospeech.VoiceSelectionParams(
        language_code="vi-VN",
        name=voice_name,  # "vi-VN-Neural2-A" (female), "vi-VN-Neural2-D" (male)
    )
    audio_config = texttospeech.AudioConfig(
        audio_encoding=texttospeech.AudioEncoding.MP3,
        speaking_rate=1.0,
        pitch=0.0
    )
    
    response = client.synthesize_speech(input=input_text, voice=voice, audio_config=audio_config)
    with open(output_path, "wb") as out:
        out.write(response.audio_content)

🗄️ 7. Database Schema

-- ═══════════════════════════════════════════════════════════
-- AUDIOBOOK PIPELINE TABLES
-- ═══════════════════════════════════════════════════════════

-- 1. Audio Chapters (published audio linked to a publication)
CREATE TABLE "AudioChapters" (
    "Id" UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    "PublicationId" UUID NOT NULL REFERENCES "Publications"("Id"),
    "ChapterNumber" DECIMAL NOT NULL,
    "Title" VARCHAR(200),
    "AudioUrl" VARCHAR(500) NOT NULL,              -- Path to final MP3/M4A
    "Duration" INT NOT NULL,                       -- Duration in seconds
    "FileSize" BIGINT,                             -- File size in bytes
    "IsLocked" BOOLEAN DEFAULT FALSE,
    "CoinPrice" INT DEFAULT 0,
    "ListenCount" INT DEFAULT 0,
    "WaveformData" TEXT,                           -- JSON array for player visualization
    "CreatedAt" TIMESTAMP DEFAULT NOW()
);

-- 2. Audio Generation Jobs
CREATE TABLE "AudioJobs" (
    "Id" UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    "PublicationId" UUID NOT NULL REFERENCES "Publications"("Id"),
    "SourceType" VARCHAR(20) NOT NULL,             -- 'book_chapter', 'comic_chapter', 'manual_script', 'upload'
    "SourceChapterIds" TEXT,                       -- JSON array of source chapter IDs
    "TargetLanguage" VARCHAR(10) DEFAULT 'vi',
    "Status" VARCHAR(30) NOT NULL DEFAULT 'pending',
    -- Status: pending → preprocessing → generating → post_processing → review → approved → published → failed
    "TtsProvider" VARCHAR(50),                     -- 'edge_tts', 'google_cloud', 'openai', 'fpt_ai'
    "NarratorVoiceId" VARCHAR(100),
    "TotalSegments" INT DEFAULT 0,
    "ProcessedSegments" INT DEFAULT 0,
    "ErrorMessage" TEXT,
    "Settings" TEXT,                               -- JSON: { speed, addBgm, bgmVolume, ... }
    "CreatedBy" VARCHAR(100),
    "CreatedAt" TIMESTAMP DEFAULT NOW(),
    "CompletedAt" TIMESTAMP
);

-- 3. Audio Segments (individual TTS chunks within a job)
CREATE TABLE "AudioSegments" (
    "Id" UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    "JobId" UUID NOT NULL REFERENCES "AudioJobs"("Id") ON DELETE CASCADE,
    "OrderIndex" INT NOT NULL,
    "SegmentType" VARCHAR(20) NOT NULL,            -- 'narration', 'dialog', 'sfx', 'pause'
    "Text" TEXT,                                   -- Text content to speak
    "VoiceProfileId" VARCHAR(100),
    "Speaker" VARCHAR(100),                        -- Character name
    "Emotion" VARCHAR(50),                         -- happy, sad, angry, neutral
    "Speed" DECIMAL(3,2) DEFAULT 1.0,
    "PauseAfterMs" INT DEFAULT 500,
    "AudioChunkUrl" VARCHAR(500),                  -- Path to generated audio chunk
    "Duration" INT,                                -- Chunk duration in ms
    "Status" VARCHAR(20) DEFAULT 'pending'         -- pending, generating, done, failed
);

-- 4. Voice Profiles (admin-managed voices)
CREATE TABLE "VoiceProfiles" (
    "Id" VARCHAR(100) PRIMARY KEY,                 -- 'narrator_male', 'male_hero', etc.
    "DisplayName" VARCHAR(100) NOT NULL,
    "VoiceType" VARCHAR(20) NOT NULL,              -- 'narrator', 'character', 'sfx'
    "Gender" VARCHAR(10),                          -- 'male', 'female', 'neutral'
    "TtsProvider" VARCHAR(50) NOT NULL,
    "TtsVoiceId" VARCHAR(200) NOT NULL,            -- Provider-specific voice ID
    "Settings" TEXT,                               -- JSON: { pitch, speed, style, ... }
    "SampleAudioUrl" VARCHAR(500),                 -- Preview audio sample
    "IsActive" BOOLEAN DEFAULT TRUE
);

-- 5. Character Voice Mappings (per publication)
CREATE TABLE "CharacterVoiceMappings" (
    "Id" UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    "PublicationId" UUID NOT NULL REFERENCES "Publications"("Id"),
    "CharacterName" VARCHAR(100) NOT NULL,
    "VoiceProfileId" VARCHAR(100) REFERENCES "VoiceProfiles"("Id"),
    "Notes" VARCHAR(200)
);

-- 6. Audio SFX Library
CREATE TABLE "AudioSfxLibrary" (
    "Id" UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    "Name" VARCHAR(100) NOT NULL,                  -- 'explosion', 'sword_slash', 'thunder'
    "Category" VARCHAR(50),                        -- 'combat', 'nature', 'emotion', 'magic'
    "Keywords" TEXT,                               -- JSON array: ["boom", "đùng", "nổ"]
    "AudioUrl" VARCHAR(500) NOT NULL,
    "Duration" INT                                 -- ms
);

-- Indexes
CREATE INDEX idx_audio_chapters_pub ON "AudioChapters"("PublicationId", "ChapterNumber");
CREATE INDEX idx_audio_jobs_pub ON "AudioJobs"("PublicationId");
CREATE INDEX idx_audio_jobs_status ON "AudioJobs"("Status");
CREATE INDEX idx_audio_segments_job ON "AudioSegments"("JobId", "OrderIndex");

Tối ưu hóa

  • Cache audio chunks: Nếu text không đổi → dùng lại chunk đã generate (không gọi TTS API lại)
  • Batch processing: Group nhiều segments vào 1 API call (Google/Azure support batch)
  • Lazy generation: Chỉ generate khi có demand (user request nghe → generate lần đầu → cache)
  • Quality tiering: Free users nghe Edge TTS (chất lượng OK), VIP users nghe OpenAI TTS (chất lượng cao)
  • Streaming: Stream audio thay vì download toàn bộ → giảm bandwidth

Task AU2: Python Worker — TTS Service

Dự án: python-worker/ (mở rộng từ Translation Pipeline)

Endpoint mới: POST /tts/generate
Body: {
  segments: [
    { text: "...", voice: "vi-VN-NamMinhNeural", speed: 1.0, provider: "edge_tts" },
    ...
  ],
  outputFormat: "mp3",
  outputPath: "/uploads/audio/jobs/{jobId}/full.mp3"
}
Response: { success: true, duration: 745, fileSize: 8923456, outputUrl: "..." }

Logic:
1. For each segment: call TTS API → save chunk
2. Concatenate chunks with ffmpeg/pydub
3. Normalize volume (pydub.effects.normalize)
4. Add silence gaps between segments
5. (Optional) Mix background music
6. Export final MP3

Dependencies: edge-tts, pydub, ffmpeg-python
Optional: google-cloud-texttospeech, openai

Task AU3: Python Worker — Text Preprocessor

Dự án: python-worker/

Endpoint: POST /audio/preprocess
Body: {
  sourceType: "book_chapter",
  content: "
Trời đêm tối...
\"Ngươi là ai?\"...
",
  characterVoices: { "Lâm Phong": "male_hero", ... },
  defaultNarrator: "narrator_male",
  language: "vi"
}
Response: {
  segments: [
    { index: 0, type: "narration", text: "...", voice: "narrator_male", speed: 1.0, pauseAfter: 800 },
    { index: 1, type: "dialog", text: "...", voice: "male_hero", speaker: "Lâm Phong", ... },
    ...
  ],
  totalSegments: 45,
  estimatedDuration: 720
}

Logic:
1. Strip HTML tags, preserve paragraph breaks
2. Regex detect dialog: text between "" or 「」 or ''
3. Detect speaker from context (regex: "X nói", "X hét", "- X")
4. Map speaker → voice profile
5. Split long paragraphs into segments (~300 chars max)
6. Assign pause durations
7. Return structured AudioScript

1. Tổng Quan & Lý Do Chuyển Đổi

1.1 Vấn đề hiện tại

  • Tất cả bảng admin đang dùng pagination truyền thống (page 1, 2, 3... với 10-20 dòng/trang)
  • Khi có 500+ bản ghi, người dùng phải click qua nhiều trang để xem hết
  • Mất context khi chuyển trang — không nhìn được dòng trước đó
  • Mỗi lần chuyển trang → re-render toàn bộ bảng → giật

1.2 Giải pháp: Infinite Scroll (kiểu Jira)

  • Load 50 dòng đầu tiên → user cuộn xuống → tự động load thêm 50 dòng tiếp
  • Hiển thị tooltip "⟳ Loading more" ở cuối bảng khi đang fetch
  • Footer hiển thị "50 of 149" — biết đang ở đâu trong tổng số
  • Giữ nguyên tất cả tính năng: inline edit, sort, search, bulk select, upload
  • API backend không thay đổi gì — vẫn dùng ?page=X&pageSize=Y

4. Custom Hook: useInfiniteScroll

📁 xmtruyen-admin/src/hooks/useInfiniteScroll.ts
import { useState, useCallback, useRef, useEffect } from 'react';
import type { PaginatedResponse } from '../api/userApi';

// ============================================================
// useInfiniteScroll — Hook tái sử dụng cho toàn bộ bảng Admin
// ============================================================

interface UseInfiniteScrollOptions<T, P = any> {
    /** Hàm fetch dữ liệu — trả về { data, totalCount, page, pageSize } */
    fetchFn: (params: P & { page: number; pageSize: number }) => Promise<PaginatedResponse<T>>;
    /** Số dòng mỗi lần load (default: 50) */
    pageSize?: number;
    /** Các params filter/search — khi thay đổi sẽ reset về trang 1 */
    params?: P;
    /** Có tự động load lần đầu không (default: true) */
    autoLoad?: boolean;
}

interface UseInfiniteScrollReturn<T> {
    /** Mảng tích lũy toàn bộ items đã load */
    items: T[];
    /** Tổng số bản ghi từ backend */
    totalCount: number;
    /** Đang load lần đầu */
    isLoading: boolean;
    /** Đang load thêm (page 2, 3...) */
    isLoadingMore: boolean;
    /** Còn dữ liệu để load thêm không */
    hasMore: boolean;
    /** Số items đã load */
    loadedCount: number;
    /** Ref gắn vào sentinel element (div cuối bảng) */
    sentinelRef: React.RefObject<HTMLDivElement | null>;
    /** Reset về trang 1 (khi filter/search thay đổi) */
    reset: () => void;
    /** Reload toàn bộ dữ liệu đã load (giữ nguyên vị trí) */
    refresh: () => void;
    /** Cập nhật 1 item trong mảng (inline edit) */
    updateItem: (id: string, updater: (item: T) => T) => void;
    /** Xóa 1 item khỏi mảng (optimistic delete) */
    removeItem: (id: string) => void;
    /** Thêm 1 item vào đầu mảng (sau khi tạo mới) */
    prependItem: (item: T) => void;
}

export function useInfiniteScroll<T extends { id: string }, P = any>({
    fetchFn,
    pageSize = 50,
    params,
    autoLoad = true,
}: UseInfiniteScrollOptions<T, P>): UseInfiniteScrollReturn<T> {
    const [items, setItems] = useState<T[]>([]);
    const [totalCount, setTotalCount] = useState(0);
    const [currentPage, setCurrentPage] = useState(0); // 0 = chưa load gì
    const [isLoading, setIsLoading] = useState(false);
    const [isLoadingMore, setIsLoadingMore] = useState(false);

    const sentinelRef = useRef<HTMLDivElement | null>(null);
    const observerRef = useRef<IntersectionObserver | null>(null);
    const isFetchingRef = useRef(false); // Tránh race condition

    const hasMore = items.length < totalCount;

    // ─── Fetch page tiếp theo ───
    const fetchNextPage = useCallback(async (isInitial = false) => {
        if (isFetchingRef.current) return;
        isFetchingRef.current = true;

        const nextPage = isInitial ? 1 : currentPage + 1;

        if (isInitial) {
            setIsLoading(true);
        } else {
            setIsLoadingMore(true);
        }

        try {
            const res = await fetchFn({
                ...params as any,
                page: nextPage,
                pageSize
            });

            if (isInitial) {
                setItems(res.data);
            } else {
                setItems(prev => [...prev, ...res.data]);
            }
            setTotalCount(res.totalCount);
            setCurrentPage(nextPage);
        } catch (err) {
            console.error('[useInfiniteScroll] Fetch error:', err);
        } finally {
            setIsLoading(false);
            setIsLoadingMore(false);
            isFetchingRef.current = false;
        }
    }, [fetchFn, params, currentPage, pageSize]);

    // ─── Load lần đầu ───
    useEffect(() => {
        if (autoLoad) {
            fetchNextPage(true);
        }
    }, []); // eslint-disable-line react-hooks/exhaustive-deps

    // ─── Reset khi params thay đổi (search, filter) ───
    const paramsRef = useRef(params);
    useEffect(() => {
        // So sánh shallow
        if (JSON.stringify(paramsRef.current) !== JSON.stringify(params)) {
            paramsRef.current = params;
            setItems([]);
            setCurrentPage(0);
            setTotalCount(0);
            // Debounce để tránh fetch liên tục khi user đang gõ
            const timer = setTimeout(() => {
                fetchNextPage(true);
            }, 300);
            return () => clearTimeout(timer);
        }
    }, [params]); // eslint-disable-line react-hooks/exhaustive-deps

    // ─── Intersection Observer — phát hiện sentinel vào viewport ───
    useEffect(() => {
        if (observerRef.current) {
            observerRef.current.disconnect();
        }

        observerRef.current = new IntersectionObserver(
            (entries) => {
                const entry = entries[0];
                if (entry.isIntersecting && hasMore && !isFetchingRef.current) {
                    fetchNextPage(false);
                }
            },
            {
                threshold: 0.1,
                rootMargin: '200px' // Bắt đầu fetch trước khi user cuộn tới sentinel 200px
            }
        );

        if (sentinelRef.current) {
            observerRef.current.observe(sentinelRef.current);
        }

        return () => observerRef.current?.disconnect();
    }, [hasMore, fetchNextPage]);

    // ─── Public methods ───
    const reset = useCallback(() => {
        setItems([]);
        setCurrentPage(0);
        setTotalCount(0);
        setTimeout(() => fetchNextPage(true), 0);
    }, [fetchNextPage]);

    const refresh = useCallback(async () => {
        // Reload tất cả pages đã load (giữ scroll position)
        isFetchingRef.current = true;
        setIsLoading(true);
        try {
            const totalPages = currentPage;
            const allItems: T[] = [];
            for (let p = 1; p <= totalPages; p++) {
                const res = await fetchFn({ ...params as any, page: p, pageSize });
                allItems.push(...res.data);
                setTotalCount(res.totalCount);
            }
            setItems(allItems);
        } catch (err) {
            console.error('[useInfiniteScroll] Refresh error:', err);
        } finally {
            setIsLoading(false);
            isFetchingRef.current = false;
        }
    }, [fetchFn, params, currentPage, pageSize]);

    const updateItem = useCallback((id: string, updater: (item: T) => T) => {
        setItems(prev => prev.map(item => item.id === id ? updater(item) : item));
    }, []);

    const removeItem = useCallback((id: string) => {
        setItems(prev => prev.filter(item => item.id !== id));
        setTotalCount(prev => prev - 1);
    }, []);

    const prependItem = useCallback((item: T) => {
        setItems(prev => [item, ...prev]);
        setTotalCount(prev => prev + 1);
    }, []);

    return {
        items,
        totalCount,
        isLoading,
        isLoadingMore,
        hasMore,
        loadedCount: items.length,
        sentinelRef,
        reset,
        refresh,
        updateItem,
        removeItem,
        prependItem,
    };
}

8. Hướng Dẫn Migration Từng Trang

8.1 Checklist cho mỗi trang (5 bước)

  1. Import hook: import { useInfiniteScroll } from '../hooks/useInfiniteScroll';
  2. Xóa state cũ: Xóa currentPage, itemsPerPage, totalPages, refreshTrigger và useEffect fetch
  3. Thêm hook: Gọi useInfiniteScroll với fetchFn tương ứng
  4. Thêm sentinel: Đặt <div ref={sentinelRef} className="scroll-sentinel" /> ngay sau </table>
  5. Thay footer: Dùng <InfiniteScrollFooter /> thay pagination controls

9. Xử Lý Edge Cases

🔍 Search thay đổi

Khi user gõ search → params thay đổi → hook tự động reset về page 1 (với debounce 300ms). Mảng items bị clear và load lại từ đầu.

✏️ Inline Edit

Sau khi save → gọi updateItem(id, updater) để cập nhật ngay trong mảng. Không cần re-fetch toàn bộ → giữ scroll position.

🗑️ Delete

Gọi removeItem(id) → xóa ngay khỏi mảng + giảm totalCount. Không bị "lỗ" trong danh sách. Nếu xóa nhiều (bulk) → gọi refresh() sau.

➕ Create New

Gọi prependItem(newItem) → thêm vào đầu mảng + tăng totalCount. Item mới hiển thị ngay trên đầu bảng.

🔄 Sort

Sort chỉ áp dụng client-side trên items đã load. Nếu muốn sort server-side → thêm sortBy vào params → hook tự reset.

📶 Mất mạng giữa chừng

Nếu fetchMore thất bại → isLoadingMore trở về false, sentinel vẫn visible → user cuộn lại sẽ trigger retry tự động.

⚡ Race Condition

isFetchingRef đảm bảo chỉ 1 request đang chạy tại 1 thời điểm. Intersection Observer trigger nhiều lần cũng chỉ 1 fetch.

📱 Table Scroll Container

Sentinel element đặt bên trong .jira-scroll div (container có overflow-y: auto). Observer dùng rootMargin "200px" → fetch trước khi user tới cuối.

10. Backend API — Không Cần Thay Đổi

💡 Điểm mạnh: Backend API giữ nguyên 100%. Tất cả endpoint đã hỗ trợ ?page=X&pageSize=Y và trả về { data, totalCount, page, pageSize }. Chỉ frontend thay đổi cách sử dụng response.

10.1 Response Format hiện tại (giữ nguyên)

// GET /api/Publications?page=2&pageSize=50&keyword=harry
// Response:
{
    "data": [ /* 50 items */ ],
    "totalCount": 149,
    "page": 2,
    "pageSize": 50
}

// TypeScript type (đã có sẵn):
export interface PaginatedResponse<T> {
    data: T[];
    totalCount: number;
    page: number;
    pageSize: number;
}

10.2 Khuyến nghị tối ưu backend (không bắt buộc)

Tối ưu Mô tả Ưu tiên
Cursor-based pagination Thay ?page=X bằng ?cursor=lastId cho dataset lớn (>10k rows). Tránh OFFSET chậm. Thấp (chỉ khi >10k)
Response caching Thêm ETag / Last-Modified header để client skip re-fetch nếu data không đổi. Trung bình
Giới hạn pageSize tối đa Server reject nếu pageSize > 100 để tránh query quá nặng. Cao (nên làm)

💡 Chiến lược crawl

  • Nguồn VN (C): Crawl → publish trực tiếp (không cần dịch) — nhanh nhất, có content ngay

Xử lý đặc biệt cho ảnh truyện tranh

Vấn đềMô tảGiải pháp
Hotlink protection Site chặn download ảnh nếu không có đúng Referer header Set Referer header = page URL khi download image
Lazy-load images Ảnh chỉ load khi scroll đến (data-src thay vì src) Dùng Playwright scroll toàn trang, hoặc parse data-src trực tiếp
Long-strip format (Manhwa) 1 chapter = 1 ảnh cực dài (10000px+) Auto-split thành pages 1200px height mỗi page
Watermark Nguồn có watermark text trên ảnh AI remove watermark (optional) hoặc crop edges
Low quality sources Ảnh nén nhiều, bị blur AI upscale (waifu2x / Real-ESRGAN) — tùy chọn
Dynamic image URLs URL ảnh thay đổi mỗi lần load (token-based) Fetch + download ngay trong cùng session, không cache URL
CDN rate limit CDN chặn nếu download quá nhanh Delay 500ms-1s giữa mỗi ảnh, retry với exponential backoff

Ví dụ: Crawl từ MangaDex API (có API chính thức)

# MangaDex có REST API public — dễ crawl nhất

import requests, time

BASE = "https://api.mangadex.org"

# 1. Search manga
resp = requests.get(f"{BASE}/manga", params={"title": "Solo Leveling", "limit": 5})
manga_id = resp.json()["data"][0]["id"]

# 2. Get chapters
resp = requests.get(f"{BASE}/manga/{manga_id}/feed", params={
    "translatedLanguage[]": "ko",  # Korean raw
    "order[chapter]": "asc",
    "limit": 100
})
chapters = resp.json()["data"]

# 3. Get chapter images
for ch in chapters:
    ch_id = ch["id"]
    time.sleep(1)  # Rate limit: 5 req/s
    
    # Get image server + filenames
    resp = requests.get(f"{BASE}/at-home/server/{ch_id}")
    server = resp.json()
    base_url = server["baseUrl"]
    chapter_hash = server["chapter"]["hash"]
    pages = server["chapter"]["data"]  # ["page1.jpg", "page2.jpg", ...]
    
    # 4. Download images
    for i, page_filename in enumerate(pages):
        img_url = f"{base_url}/data/{chapter_hash}/{page_filename}"
        img_data = requests.get(img_url).content
        
        with open(f"chapter_{ch['attributes']['chapter']}/page_{i+1:03d}.jpg", "wb") as f:
            f.write(img_data)
        
        time.sleep(0.5)  # Gentle rate limit

🛡️ 5. Anti-ban & Proxy rotation

Chiến lược tránh bị block

Kỹ thuậtMô tảImplementation
Request delay Random delay 2-5s giữa mỗi request await asyncio.sleep(random.uniform(2, 5))
User-Agent rotation Đổi UA mỗi request, giả lập nhiều browser Pool 50+ UA strings (Chrome, Firefox, Safari, Mobile)
Proxy rotation Đổi IP mỗi 10-20 requests Dùng proxy pool (free: ProxyScrape / paid: BrightData, SmartProxy)
Session management Giữ cookies, giả lập user thật requests.Session() với persistent cookies
Headless browser Render JS cho sites có anti-bot (Cloudflare, etc.) Playwright / Puppeteer (stealth mode)
Respectful crawling Không crawl quá nhanh, không DDoS Max 1 request/3s per domain, 30 chapters/run
Error handling Retry với backoff khi bị 403/429 Exponential backoff: 5s → 15s → 45s → skip

# Hoặc paid proxy (reliable):
# BrightData: $15/GB — residential proxies
# SmartProxy: $12.5/GB — datacenter + residential

class ProxyRotator:
    def __init__(self):
        self.proxies = self.fetch_proxies()
        self.index = 0
    
    def get_next(self):
        proxy = self.proxies[self.index % len(self.proxies)]
        self.index += 1
        return {"http": f"http://{proxy}", "https": f"http://{proxy}"}
    
    def mark_dead(self, proxy):
        self.proxies.remove(proxy)

⏰ 6. Scheduler — Lịch crawl tự động

SCHEDULER WORKFLOW: ┌────────────────────────────────────────────────────────────┐ │ CRON JOB (chạy mỗi 30 phút) │ │ │ │ 1. Load active CrawlSources từ DB │ │ 2. For each source: │ │ ├── Check: lastCrawlAt + interval < NOW()? │ │ │ └── No → skip │ │ ├── Yes → Fetch chapter list page │ │ ├── Compare: server chapter count vs DB count │ │ │ └── Same → skip (no new chapters) │ │ ├── New chapters found! │ │ │ ├── Crawl new chapters (content/images) │ │ │ ├── Execute autoAction: │ │ │ │ • "publish" → create chapters directly │ │ │ │ • "translate" → create TranslationJob │ │ │ │ • "queue" → just save, wait for admin │ │ │ ├── Update source.lastCrawlAt │ │ │ └── Notify admin: "3 chương mới đã crawl" │ │ └── Error? → log error, retry next cycle │ │ │ │ 3. Health check: sources offline? selectors broken? │ │ └── Alert admin if source returns 404 or empty │ └────────────────────────────────────────────────────────────┘ SCHEDULE OPTIONS (per source): • "30m" — mỗi 30 phút (cho truyện daily update) • "2h" — mỗi 2 giờ (default) • "6h" — mỗi 6 giờ (cho truyện weekly) • "1d" — mỗi ngày • "manual" — chỉ chạy khi admin bấm

-- ═══════════════════════════════════════════════════════════

-- 1. Crawl Sources (cấu hình mỗi truyện cần crawl)
CREATE TABLE "CrawlSources" (
    "Id" UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    "PublicationId" UUID REFERENCES "Publications"("Id"),  -- Link to local publication (null if not created yet)
    "SourceName" VARCHAR(100) NOT NULL,                    -- "69shu", "rawkuma", "nettruyen"
    "SourceUrl" VARCHAR(500) NOT NULL,                     -- URL trang truyện
    "SourceType" VARCHAR(20) NOT NULL,                     -- 'novel', 'comic'
    "SourceLanguage" VARCHAR(10) NOT NULL,                 -- 'zh', 'ko', 'ja', 'vi', 'en'
    "Selectors" TEXT NOT NULL,                             -- JSON config selectors
    "CrawlConfig" TEXT,                                    -- JSON: delay, proxy, userAgent, encoding
    "AutoAction" VARCHAR(30) DEFAULT 'queue',              -- 'publish', 'translate', 'audiobook', 'queue'
    "ScheduleInterval" VARCHAR(20) DEFAULT '2h',           -- '30m', '2h', '6h', '1d', 'manual'
    "IsActive" BOOLEAN DEFAULT TRUE,
    "LastCrawlAt" TIMESTAMP,
    "LastChapterCrawled" INT DEFAULT 0,
    "TotalChaptersCrawled" INT DEFAULT 0,
    "ErrorCount" INT DEFAULT 0,                            -- Consecutive errors
    "LastError" TEXT,
    "CreatedAt" TIMESTAMP DEFAULT NOW(),
    "UpdatedAt" TIMESTAMP DEFAULT NOW()
);

-- 2. Crawl Chapters (mỗi chương đã crawl về)
CREATE TABLE "CrawlChapters" (
    "Id" UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    "SourceId" UUID NOT NULL REFERENCES "CrawlSources"("Id") ON DELETE CASCADE,
    "ChapterNumber" DECIMAL NOT NULL,
    "Title" VARCHAR(300),
    "SourceChapterUrl" VARCHAR(500),                       -- URL gốc của chương
    "RawContent" TEXT,                                     -- Text content (for novels)
    "ImageFolder" VARCHAR(500),                            -- Path to downloaded images (for comics)
    "ImageCount" INT DEFAULT 0,
    "Status" VARCHAR(30) DEFAULT 'pending',                -- 'pending', 'crawling', 'crawled', 'published', 'failed'
    "PublishedChapterId" UUID,                             -- FK to BookChapter/ComicChapter after publish
    "FileSize" BIGINT DEFAULT 0,                           -- Total size of downloaded content
    "CrawledAt" TIMESTAMP,
    "CreatedAt" TIMESTAMP DEFAULT NOW()
);

-- 3. Crawl Runs (log mỗi lần chạy crawl)
CREATE TABLE "CrawlRuns" (
    "Id" UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    "SourceId" UUID NOT NULL REFERENCES "CrawlSources"("Id"),
    "TriggerType" VARCHAR(20) NOT NULL,                    -- 'scheduled', 'manual', 'auto_update'
    "Status" VARCHAR(20) NOT NULL DEFAULT 'running',       -- 'running', 'completed', 'failed', 'cancelled'
    "ChaptersCrawled" INT DEFAULT 0,
    "ChaptersNew" INT DEFAULT 0,
    "ImagesDownloaded" INT DEFAULT 0,
    "BytesDownloaded" BIGINT DEFAULT 0,
    "Duration" INT,                                        -- Duration in seconds
    "ErrorMessage" TEXT,
    "StartedAt" TIMESTAMP DEFAULT NOW(),
    "CompletedAt" TIMESTAMP
);

-- 4. Crawl Site Templates (pre-built selector configs cho sites phổ biến)
CREATE TABLE "CrawlSiteTemplates" (
    "Id" VARCHAR(50) PRIMARY KEY,                          -- '69shu', 'rawkuma', 'nettruyen', 'mangadex'
    "SiteName" VARCHAR(100) NOT NULL,
    "SiteUrl" VARCHAR(200),
    "SourceType" VARCHAR(20) NOT NULL,
    "Language" VARCHAR(10),
    "SelectorsTemplate" TEXT NOT NULL,                     -- JSON default selectors
    "CrawlConfigTemplate" TEXT,                            -- JSON default crawl config
    "Notes" TEXT,
    "IsActive" BOOLEAN DEFAULT TRUE
);

-- Indexes
CREATE INDEX idx_crawl_sources_active ON "CrawlSources"("IsActive", "ScheduleInterval");
CREATE INDEX idx_crawl_chapters_source ON "CrawlChapters"("SourceId", "ChapterNumber");
CREATE INDEX idx_crawl_chapters_status ON "CrawlChapters"("Status");
CREATE INDEX idx_crawl_runs_source ON "CrawlRuns"("SourceId", "StartedAt" DESC);

🔌 8. API Endpoints

AdminCrawlerController [Authorize(Roles="Admin")]

// ─── SOURCE MANAGEMENT ───
GET    /api/admin/crawler/sources?isActive=&type=&page=1
       → List crawl sources (filter by type, status)

GET    /api/admin/crawler/sources/{id}
       → Source detail + recent runs + chapter stats

POST   /api/admin/crawler/sources
       Body: { sourceUrl, sourceName, sourceType, sourceLanguage, selectors, crawlConfig, autoAction, scheduleInterval }
       → Create new crawl source

PUT    /api/admin/crawler/sources/{id}
       → Update source config (selectors, schedule, etc.)

PATCH  /api/admin/crawler/sources/{id}/toggle
       → Enable/Disable source

DELETE /api/admin/crawler/sources/{id}
       → Delete source + all crawled data

// ─── CRAWL ACTIONS ───
POST   /api/admin/crawler/sources/{id}/crawl-now
       Body: { chapterRange: "1-50" (optional), force: false }
       → Trigger manual crawl immediately

POST   /api/admin/crawler/sources/{id}/test
       Body: { testUrl: "chapter URL" (optional) }
       → Test crawl 1 page, return extracted data (for debugging selectors)

POST   /api/admin/crawler/sources/{id}/stop
       → Cancel running crawl

// ─── CHAPTERS ───
GET    /api/admin/crawler/sources/{id}/chapters?status=&page=1
       → List crawled chapters for this source

GET    /api/admin/crawler/chapters/{chapterId}/preview
       → Preview raw content (text or first few images)

POST   /api/admin/crawler/chapters/publish

Task CR4: Backend — Scheduler Service (Hangfire)

Dự án: xmtruyen.API

Tạo: Services/CrawlSchedulerService.cs
- Registered as Hangfire RecurringJob (chạy mỗi 5 phút)
- Logic:
  1. var sources = await _db.CrawlSources.Where(s => s.IsActive).ToListAsync();
  2. foreach source: check if due (lastCrawlAt + interval < now)
  3. If due: enqueue crawl job (Hangfire BackgroundJob.Enqueue)
  4. Crawl job:
     a. Call Python /crawler/check-updates
     b. If new chapters → Call Python /crawler/crawl-novel or /crawl-comic
     c. Save CrawlChapters to DB
     d. Execute autoAction (publish/translate/queue)
     e. Update source.LastCrawlAt
     f. Create CrawlRun log

Setup trong Program.cs:
services.AddHangfire(config => config.UsePostgreSqlStorage(connectionString));
app.UseHangfireDashboard("/hangfire");
RecurringJob.AddOrUpdate("crawl-scheduler", x => x.RunAsync(), "*/5 * * * *");

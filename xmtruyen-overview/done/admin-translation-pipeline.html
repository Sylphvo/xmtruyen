📥 3. Step 1: Upload RAW files

Input:

  • File ZIP/CBZ/RAR chứa ảnh truyện tranh gốc (chưa dịch)
  • Hoặc: folder path trên server (nếu đã crawl về)
  • Metadata: Publication ID, Chapter range (VD: chapter 1-10), Source language

Xử lý:

  1. Extract archive → tạo folder structure: 
    /uploads/raw/{publicationId}/
  ├── chapter_001/
  │   ├── page_001.jpg
  │   ├── page_002.jpg
  │   └── page_003.jpg
  ├── chapter_002/
  │   ├── page_001.jpg
  │   └── ...
  └── chapter_003/
      └── ...
  2. Auto-detect chapter structure (by folder name hoặc file naming pattern)
  3. Convert to WebP nếu cần (giảm size)
  4. Tạo record TranslationJob + TranslationChapter records

Output:

  • RAW images organized theo chapter/page
  • TranslationJob status = imported

Admin UI cho Step 1

  • Form upload: Chọn Publication (dropdown search), Chapter start number, Source language (CN/KR/JP/EN), Target language (VI), Upload file (ZIP/CBZ drag-drop)
  • Bulk import: Upload 1 ZIP chứa nhiều chapters (auto-detect folders)
  • Preview: Sau khi extract, hiển thị grid thumbnail các trang đầu tiên để confirm
  • Progress bar: Upload + extract progress

🔍 4. Step 2: OCR — Nhận diện text trong ảnh

Input:

  • Ảnh RAW manga/manhwa/manhua
  • Source language setting (để chọn OCR model phù hợp)

Xử lý:

  1. Text Detection: Tìm vùng chứa text (speech bubbles, SFX, narration boxes)
  2. Text Recognition: Đọc nội dung text trong mỗi vùng
  3. Output per block: 
    {
  "id": "block_001",
  "pageIndex": 0,
  "bbox": { "x": 120, "y": 45, "width": 200, "height": 80 },
  "originalText": "俺は最強だ！",
  "confidence": 0.95,
  "textType": "dialog",        // dialog, sfx, narration, title
  "fontStyle": "bold",
  "fontSize": 24
}

Công cụ OCR theo ngôn ngữ:

Ngôn ngữ nguồnOCR Tool khuyến nghịAccuracyGhi chú
🇨🇳 Chinese (Manhua) PaddleOCR 95%+ Best cho Chinese text, free, fast
🇰🇷 Korean (Manhwa) PaddleOCR Tesseract-kor 90-95% PaddleOCR supports Korean well
🇯🇵 Japanese (Manga) manga-ocr PaddleOCR 92-97% manga-ocr chuyên cho manga (vertical text)
🇺🇸 English Tesseract-eng EasyOCR 98%+ Dễ nhất, accuracy cao

Xử lý đặc biệt cho manga/manhwa

Thách thức:

  • Vertical text (JP): Manga JP thường viết dọc → cần OCR model hỗ trợ vertical
  • SFX (Sound effects): Text vẽ tay, không nằm trong bubble → khó detect. Có thể bỏ qua hoặc manual tag
  • Stylized fonts: Text artistic/decorative → OCR confidence thấp → cần human review
  • Overlapping text: Text chồng lên nhau hoặc lên artwork → cần AI segmentation tốt

Giải pháp:

  • Dùng 2-pass OCR: Pass 1 (auto) → Pass 2 (human verify các block confidence < 0.8)
  • Train custom model cho SFX phổ biến (ドドド, 바사삭, 轰隆隆)
  • Cho admin manual add/edit text blocks trên UI nếu OCR miss

🌍 5. Step 3: AI Translation — Dịch text

Input:

  • List text blocks + original text
  • Source language + Target language
  • Context: publication genre, character names, previous translations

Xử lý:

  1. Group text blocks by page (để AI có context đoạn hội thoại)
  2. Send batch to translation API với prompt chuyên biệt
  3. Post-process: Kiểm tra length (text dịch phải fit vào bbox), format

Translation API Prompt Design

Rules:
1. Keep translations SHORT - they must fit in small speech bubbles

6. Format: Return JSON array matching input order

CONTEXT:
- Genre: {genre} (Tiên Hiệp / Action / Romance)
- Publication: {title}
- Chapter: {chapterNumber}
- Character speaking: {characterName} (if known)

INPUT (page {pageNum}, {blockCount} blocks):

🎨 6. Step 4: Typesetting — Chèn text dịch vào ảnh

Input:

  • Ảnh RAW gốc
  • Text blocks với translated text + bbox coordinates

Xử lý (per image):

  1. MASK: Tạo mask vùng text gốc (dựa trên bbox)
  2. INPAINT: Xóa text gốc, fill bằng background color/pattern 
    # Python with OpenCV
mask = create_text_mask(image, text_blocks)
inpainted = cv2.inpaint(image, mask, inpaintRadius=3, flags=cv2.INPAINT_TELEA)
# Hoặc dùng LaMa AI inpainting cho kết quả tốt hơn
  3. RENDER TEXT: Vẽ text dịch vào vị trí bbox 
    # Python with Pillow
from PIL import Image, ImageDraw, ImageFont

draw = ImageDraw.Draw(inpainted_image)
font = ImageFont.truetype("manga_font.ttf", size=calculate_font_size(bbox, text))

# Auto-wrap text to fit bbox
wrapped_text = wrap_text(translated_text, font, bbox.width)
draw.text((bbox.x, bbox.y), wrapped_text, font=font, fill=text_color)
  4. STYLE: Match font style (bold cho dialog hét, italic cho suy nghĩ, large cho SFX)
  5. OUTPUT: Save as WebP (quality 85) → /uploads/translated/...

Thuật toán auto-fit text vào bubble

def fit_text_in_bbox(text: str, bbox: dict, max_font_size: int = 28) -> dict:
    """
    Tự động điều chỉnh font size và wrap text để fit vào bounding box.
    Returns: { font_size, wrapped_lines, text_position }
    """
    for font_size in range(max_font_size, 8, -1):
        font = load_font(font_size)
        lines = word_wrap(text, font, bbox['width'] - 10)  # padding 5px mỗi bên
        total_height = len(lines) * (font_size + 4)  # line height
        
        if total_height <= bbox['height'] - 10:
            # Text fits! Calculate centered position
            y_start = bbox['y'] + (bbox['height'] - total_height) // 2
            x_start = bbox['x'] + 5
            return {
                'font_size': font_size,
                'lines': lines,
                'position': (x_start, y_start)
            }
    
    # Fallback: smallest font, might overflow
    return { 'font_size': 8, 'lines': [text], 'position': (bbox['x'], bbox['y']) }

✅ 7. Step 5: QC Review — Kiểm tra & chỉnh sửa

Admin UI — Trang review dịch thuật:

  • Side-by-side view: Bên trái = ảnh RAW gốc | Bên phải = ảnh đã dịch
  • Text block overlay: Hover vào vùng text → hiển thị: original | translated | confidence
  • Inline edit: Click vào text block → sửa bản dịch → nút "Re-typeset" (render lại block đó)
  • Page navigation: Previous/Next page, jump to page
  • Actions per chapter:
    • ✅ Approve All → chuyển sang step 6
    • ❌ Reject → ghi note lý do, quay lại step 3 (re-translate specific blocks)
    • 🔄 Re-OCR page → chạy lại OCR cho page cụ thể (nếu miss text)
    • ➕ Add text block manually → vẽ bbox mới + nhập text dịch

🗄️ 9. Database Schema cho Translation Pipeline

-- ═══════════════════════════════════════════════════════════
-- TRANSLATION PIPELINE TABLES
-- ═══════════════════════════════════════════════════════════

-- 1. Translation Jobs (1 job = 1 batch upload, có thể chứa nhiều chapters)
CREATE TABLE "TranslationJobs" (
    "Id" UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    "PublicationId" UUID NOT NULL REFERENCES "Publications"("Id"),
    "SourceLanguage" VARCHAR(10) NOT NULL,          -- 'zh', 'ko', 'ja', 'en'
    "TargetLanguage" VARCHAR(10) NOT NULL,          -- 'vi', 'en', 'id', 'th'
    "Status" VARCHAR(30) NOT NULL DEFAULT 'imported',
    -- Status: imported → ocr_processing → ocr_done → translating → translated 
    --       → typesetting → typeset_done → reviewing → approved → publishing → published
    --       → rejected (can go back to translating)
    "TotalChapters" INT DEFAULT 0,
    "TotalPages" INT DEFAULT 0,
    "TotalTextBlocks" INT DEFAULT 0,
    "ProcessedPages" INT DEFAULT 0,                 -- Progress tracking
    "ErrorMessage" TEXT,
    "CreatedBy" VARCHAR(100),
    "CreatedAt" TIMESTAMP DEFAULT NOW(),
    "UpdatedAt" TIMESTAMP DEFAULT NOW(),
    "CompletedAt" TIMESTAMP
);

-- 2. Translation Chapters (mỗi chapter trong 1 job)
CREATE TABLE "TranslationChapters" (
    "Id" UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    "JobId" UUID NOT NULL REFERENCES "TranslationJobs"("Id") ON DELETE CASCADE,
    "ChapterNumber" DECIMAL NOT NULL,
    "Title" VARCHAR(200),
    "Status" VARCHAR(30) NOT NULL DEFAULT 'imported',
    "PageCount" INT DEFAULT 0,
    "TextBlockCount" INT DEFAULT 0,
    "RawFolderPath" VARCHAR(500),                   -- /uploads/raw/{pubId}/{chapter}/
    "TranslatedFolderPath" VARCHAR(500),            -- /uploads/translated/{pubId}/{chapter}/{lang}/
    "ReviewNote" TEXT,                              -- Editor note khi reject
    "ReviewedBy" VARCHAR(100),
    "ReviewedAt" TIMESTAMP,
    "PublishedChapterId" UUID,                      -- FK to ComicChapters after publish
    "CreatedAt" TIMESTAMP DEFAULT NOW()
);

-- 3. Translation Pages (mỗi trang ảnh)
CREATE TABLE "TranslationPages" (
    "Id" UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    "ChapterId" UUID NOT NULL REFERENCES "TranslationChapters"("Id") ON DELETE CASCADE,
    "PageNumber" INT NOT NULL,
    "RawImageUrl" VARCHAR(500) NOT NULL,            -- Path to original image
    "TranslatedImageUrl" VARCHAR(500),              -- Path to translated image (after typeset)
    "OcrStatus" VARCHAR(20) DEFAULT 'pending',      -- pending, processing, done, failed
    "TypesetStatus" VARCHAR(20) DEFAULT 'pending',
    "CreatedAt" TIMESTAMP DEFAULT NOW()
);

-- 4. Text Blocks (detected text regions per page)
CREATE TABLE "TextBlocks" (
    "Id" UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    "PageId" UUID NOT NULL REFERENCES "TranslationPages"("Id") ON DELETE CASCADE,
    "BboxX" INT NOT NULL,
    "BboxY" INT NOT NULL,
    "BboxWidth" INT NOT NULL,
    "BboxHeight" INT NOT NULL,
    "OriginalText" TEXT NOT NULL,
    "TranslatedText" TEXT,
    "TextType" VARCHAR(20) DEFAULT 'dialog',        -- dialog, sfx, narration, title
    "FontStyle" VARCHAR(20) DEFAULT 'regular',      -- regular, bold, italic
    "OcrConfidence" DECIMAL(3,2),                   -- 0.00 - 1.00
    "IsManualEdit" BOOLEAN DEFAULT FALSE,           -- TRUE nếu editor đã sửa tay
    "OrderIndex" INT DEFAULT 0
);

-- 5. Translation Glossary (từ điển thuật ngữ)
CREATE TABLE "TranslationGlossary" (
    "Id" UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    "SourceText" VARCHAR(200) NOT NULL,
    "TargetText" VARCHAR(200) NOT NULL,
    "SourceLanguage" VARCHAR(10) NOT NULL,
    "TargetLanguage" VARCHAR(10) NOT NULL,
    "Category" VARCHAR(50),                         -- cultivation, martial_arts, names, sfx, general
    "PublicationId" UUID,                           -- NULL = global, specific = only for this series
    "CreatedAt" TIMESTAMP DEFAULT NOW()
);

-- Indexes
CREATE INDEX idx_translation_jobs_pub ON "TranslationJobs"("PublicationId");
CREATE INDEX idx_translation_jobs_status ON "TranslationJobs"("Status");
CREATE INDEX idx_translation_chapters_job ON "TranslationChapters"("JobId");
CREATE INDEX idx_translation_pages_chapter ON "TranslationPages"("ChapterId");
CREATE INDEX idx_text_blocks_page ON "TextBlocks"("PageId");
CREATE INDEX idx_glossary_source ON "TranslationGlossary"("SourceText", "SourceLanguage", "TargetLanguage");

Task T4: Python Worker — Typeset Service

Dự án: python-worker/

Endpoint: POST /typeset/process
Body: {
  rawImageUrl: "/uploads/raw/.../page_001.jpg",
  blocks: [
    { bbox: {x, y, w, h}, translatedText: "Bản dịch", textType: "dialog", fontStyle: "bold" }
  ],
  outputPath: "/uploads/translated/.../page_001.webp",
  settings: {
    fontFamily: "CC Wild Words",
    defaultFontSize: 22,
    textColor: "#000000",
    inpaintMethod: "telea"    // telea, ns, lama
  }
}
Response: { success: true, outputUrl: "/uploads/translated/..." }

Logic:
1. Load raw image
2. Create mask from all block bboxes
3. Inpaint (remove original text)
4. For each block: fit_text_in_bbox() → render translated text
5. Save as WebP
6. Return output path

Dependencies: pillow, opencv-python, numpy
Fonts: Store in python-worker/fonts/ directory

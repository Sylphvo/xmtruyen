🚀 Hướng Dẫn Khởi Động & Cài Đặt Hệ Thống

Hướng dẫn chạy toàn bộ 5 phân hệ ứng dụng trong Workspace Xóm Truyện trên máy tính cục bộ (Local Development).

Bước 1

Khởi Động Backend API (.NET 8)

Cung cấp toàn bộ RESTful API, xác thực JWT, tương tác PostgreSQL và phân luồng tác vụ ngầm.

cd xmtruyen.API dotnet restore dotnet ef database update dotnet run
💡 Mặc định: API chạy tại http://localhost:5000 hoặc https://localhost:7001. Swagger UI tại /swagger.
Bước 2

Khởi Động Web Client (Next.js / React)

Cổng thông tin và đọc truyện trực tuyến dành cho độc giả với giao diện tối ưu SEO.

cd xom-truyen npm install npm run dev
💡 Mặc định: Web Client chạy tại http://localhost:3000.
Bước 3

Khởi Động Admin Portal (React / Vite)

Trang quản trị toàn diện với bảng AG-Grid Enterprise dành cho Quản Trị Viên và Biên Tập Viên.

cd xmtruyen-admin npm install npm run dev
💡 Mặc định: Admin Portal chạy tại http://localhost:5173.
Bước 4

Khởi Động Mobile App (Ionic 8 & Capacitor)

Ứng dụng di động đa nền tảng (Android / iOS) hỗ trợ đọc ngoại tuyến và thông báo đẩy.

cd xmtruyen-app npm install ionic serve # Hoặc build Android: npx cap sync android && npx cap open android
💡 Mặc định: Giao diện Web preview chạy tại http://localhost:8100.
Chương 2 • Trải Nghiệm Người Dùng

📖 Hướng Dẫn Sử Dụng Dành Cho Độc Giả

Các tính năng tối ưu trải nghiệm đọc sách, truyện chữ, truyện tranh trên Web và App di động.

📑

1. Trình Đọc Truyện Chữ (Novel Reader)

Hỗ trợ tùy biến chuyên sâu: Thay đổi kích thước chữ (A-/A+), khoảng cách dòng, chọn font chữ đọc sách (Literata, Merriweather, Roboto), chuyển đổi 3 chế độ nền: Tối (Dark), Sáng (Light), Vàng Dịu Mắt (Sepia).

Tự Động Cuộn Lưu Vị Trí % Đoạn Đọc Chế Độ Đọc Toàn Màn Hình
🎨

2. Trình Đọc Truyện Tranh (Comic & Webtoon Viewer)

Hỗ trợ 2 chế độ đọc: Cuộn Dọc Vô Tận (Webtoon Scroll) và Lật Từng Trang (Page-by-Page). Tự động tải trước (preload) 3 trang kế tiếp để trải nghiệm không bị gián đoạn.

Đổi Server CDN (Server 1 / Server 2) Nén Ảnh WebP Siêu Nhẹ Phóng To Kính Lúp (Zoom)
🔄

3. Đồng Bộ Tiến Độ Đọc (Auto-Sync Progress)

Hệ thống tự động ghi nhớ chương truyện và phần trăm trang bạn đang đọc. Khi bạn chuyển đổi từ Web sang Điện thoại hoặc máy tính bảng, tiến độ sẽ tự động cập nhật ngay lập tức.

Chương 3 • Xuất Bản & Biên Tập

✍️ Hướng Dẫn Tác Giả & Nhóm Dịch Thuật

Quy trình đăng truyện mới, quản lý danh sách chương, tải ảnh truyện tranh và upload tệp sách 500MB.

1

Tạo Bộ Truyện / Ấn Phẩm Mới (Create Publication)

Truy cập mục Quản Lý Truyện ➔ Thêm Mới. Điền Tên truyện, Tác giả, Tóm tắt nội dung, chọn Thể loại (Tiên Hiệp, Kiếm Hiệp, Ngôn Tình, Trinh Thám...) và tải lên Ảnh bìa (Cover Image kích thước khuyến nghị 600x900px).

2

Tạo Chương Truyện Chữ (Text Chapters)

Nhập số thứ tự chương (STT), Tiêu đề chương và nội dung. Trình soạn thảo hỗ trợ phím tắt, phân tách đoạn thông minh và chế độ Lưu Bản Nháp (Draft) hoặc Xuất Bản Ngay (Published).

3

Tải Lên Chương Truyện Tranh Hàng Loạt (Comic Pages Upload)

Kéo và thả đồng thời 50+ tệp ảnh vào khu vực Upload. Hệ thống tự động sắp xếp thứ tự trang theo tên file (01.jpg, 02.jpg...) và cho phép kéo thả hoán đổi vị trí trang trước khi bấm Lưu.

4

Tải Lên Tệp Sách Lớn 500MB (Chunked Book Upload & Worker)

Hỗ trợ tệp .zip, .epub, .cbz. Hệ thống chia nhỏ tệp thành các chunk 5MB để upload an toàn không bao giờ bị đứt gãy kết nối. Tiến trình ngầm (Background Worker) sẽ tự động giải nén và tạo các trang truyện tương ứng.

Chương 4 • Quản Trị Hệ Thống

🛡️ Hướng Dẫn Dành Cho Quản Trị Viên (Admin Portal)

Sử dụng bảng quản trị AG-Grid Enterprise, quản lý tài khoản, phân quyền Role và kiểm duyệt nội dung.

Quản lý toàn bộ danh sách tài khoản. Phân cấp 4 quyền: Admin, Moderator, Creator, Member. Cho phép Khóa tài khoản (Lockout) hoặc Kích hoạt tài khoản ngay tức thì.

Năng Suất

Tạo Nhanh Thể Loại & Tác Giả Trực Tiếp

Tính năng Inline Quick Create cho phép tạo ngay Thể loại hoặc Tác giả mới trực tiếp trên ô chọn của Form mà không cần mở tab quản trị khác hay tải lại trang.

Kiểm Duyệt

Phê Duyệt Nội Dung & Bình Luận

Khu vực kiểm duyệt giúp rà soát các truyện mới đăng tải, kiểm tra từ khóa nhạy cảm trong bình luận của độc giả và ẩn các bình luận vi phạm tiêu chuẩn cộng đồng.

Giám Sát

Theo Dõi Hàng Đợi Worker (Queue Monitor)

Xem trạng thái các tác vụ ngầm: Giải nén tệp sách 500MB, chuyển đổi định dạng ảnh, gửi email xác thực và các tác vụ tính toán thống kê lượt đọc.

Chương 5 • Kiến Trúc Kỹ Thuật

⚙️ Cơ Sở Dữ Liệu PostgreSQL & API Backend

Cấu trúc 18 bảng CSDL PostgreSQL và chuẩn kết nối RESTful API của hệ sinh thái Xóm Truyện.

Bảng CSDL (DbSet) Khóa Chính & Quan Hệ Chức Năng & Mục Đích Lưu Trữ
Users Id (Guid PK), RoleId (FK) Lưu thông tin tài khoản, mật khẩu băm, email, số dư tiền tệ, trạng thái khóa.
Publications Id (Guid PK), AuthorId (FK) Thông tin bộ truyện, tên tác phẩm, ảnh bìa, loại truyện (chữ/tranh), số lượt xem.
Chapters Id (Guid PK), PublicationId (FK) Chương truyện, số thứ tự, tiêu đề, nội dung text hoặc đánh dấu chương tranh.
ComicPages Id (Guid PK), ChapterId (FK) Danh sách các trang ảnh truyện tranh, URL CDN chính, URL CDN dự phòng, số trang (PageNumber).
ReadingProgress UserId (FK), ChapterId (FK) Lưu vết tiến độ đọc sách của từng người dùng, phần trăm cuộn trang và thời gian đọc cuối.
UploadSessions Id (Guid PK), UserId (FK) Quản lý phiên tải lên tệp 500MB, lưu danh sách các chunks đã hoàn thành để ghép tệp.
Chương 6 • Xử Lý Sự Cố

❓ Xử Lý Sự Cố & Câu Hỏi Thường Gặp (Troubleshooting)

Tổng hợp các giải pháp khắc phục sự cố kỹ thuật thường gặp khi phát triển và vận hành.

⚠️

Lỗi CORS khi gọi API từ Web Client (Port 3000) hoặc Admin (Port 5173)

Nguyên nhân: Backend API chặn các tên miền không được khai báo trong CORS Policy.

Khắc phục: Mở xmtruyen.API/Program.cs, kiểm tra chính sách CORS đã bổ sung nguồn gốc máy khách:

builder.Services.AddCors(options => { options.AddPolicy("AllowAll", policy => { policy.WithOrigins("http://localhost:3000", "http://localhost:5173", "http://localhost:8100") .AllowAnyHeader() .AllowAnyMethod() .AllowCredentials(); }); });
⚠️

Lỗi không kết nối được Cơ Sở Dữ Liệu PostgreSQL (Connection Refused)

Nguyên nhân: Dịch vụ PostgreSQL chưa chạy hoặc chuỗi kết nối (Connection String) trong appsettings.json sai mật khẩu.

Khắc phục: Kiểm tra dịch vụ PostgreSQL đang chạy ở cổng 5432 và kiểm tra chuỗi kết nối trong xmtruyen.API/appsettings.json:

"ConnectionStrings": { "DefaultConnection": "Host=localhost;Port=5432;Database=xmtruyen_db;Username=postgres;Password=YourSecurePassword" }
⚠️

Lỗi 413 (Payload Too Large) khi tải lên tệp sách hoặc ảnh truyện

Nguyên nhân: Giới hạn dung lượng yêu cầu mặc định của máy chủ Kestrel hoặc IIS bị vượt quá.

Khắc phục: Trong Program.cs đã cấu hình tăng giới hạn lên 500MB:

builder.Services.Configure<FormOptions>(options => { options.MultipartBodyLengthLimit = 524288000; // 500 MB }); builder.WebHost.ConfigureKestrel(serverOptions => { serverOptions.Limits.MaxRequestBodySize = 524288000; });

    🤖 Nhật Ký Tương Tác AI

    Lịch Sử Trò Chuyện Lập Trình

    Bản lưu trữ lịch sử trò chuyện và sửa lỗi trực tiếp giữa User và AI Assistant.

    User (17:00 10/08/2026)

    1. Hiện tại tôi đang vào truyện tranh tại sao lại ra truyện chữ sửa lại cho tôi.
    2. Khi upload các chapter như thế này thì có lưu database không và khi đang đọc truyện tranh thì load chap tương ứng theo sách.

    Antigravity AI (17:24 10/08/2026)

    Chào bạn, mình xin trả lời các câu hỏi của bạn như sau:

    1. "Khi upload các chapter như thế này thì có lưu database không?"
    Có lưu vào database bạn nhé. Trong API Backend, tính năng Upload Chapter không chỉ giải nén file .zip/.cbz để trích xuất ảnh vào thư mục tĩnh, mà còn quét và insert các bản ghi vào Database (bảng Chapter và ComicPages).

    2. "Khi đang đọc truyện tranh thì load chap tương ứng theo sách"
    Mình đã tiến hành sửa code ở Client (bookService.ts, ReadingPage.tsx, ComicReadingContent.tsx) để tự động gọi API fetch danh sách chương, truyền URL ảnh thực tế vào UI thay vì ảnh giả lập. Đã thêm tính năng "Chương trước / Chương sau".

    User (17:24 10/08/2026)

    Bị lỗi load (kèm hình ảnh báo các ảnh bị lỗi 404/không tải được URL do ảnh đang ở dạng relative).

    Antigravity AI (17:27 10/08/2026)

    Lỗi này xảy ra là do đường dẫn ảnh mà backend trả về đang ở dạng tương đối (ví dụ: uploads/chapters/...). Trình duyệt tự ghép đường dẫn đó vào URL Web Client (port 5174) thay vì API (port 5172).

    Mình đã sửa bookService.ts để tự động bắt và chèn API_BASE_URL vào đầu các đường dẫn ảnh bị thiếu domain. Bạn tải lại trang là ảnh sẽ hiển thị bình thường!

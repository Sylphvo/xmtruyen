# Ghi chú sử dụng local

Các lệnh trong skill chỉ đọc source local và database graph local.

- Dùng `orbit --help` để xem các lệnh có trong binary đang cài.
- Dùng `orbit schema gl_definition gl_edge` trước khi viết truy vấn SQL mới.
- Index lại repo sau khi đổi branch hoặc commit.
- Không dùng các lệnh truy vấn remote trong workflow của skill này.
